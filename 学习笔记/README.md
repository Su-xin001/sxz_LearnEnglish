# 学习笔记区

本目录用于存放学习过程中的笔记和心得。

## 文件命名规则

`YYYYMMDD_学习主题`

示例：`20260414_虚拟语气`

## 笔记模板字段

| 字段 | 说明 |
|------|------|
| 学习日期 | ISO格式日期 |
| 学习时长 | 分钟数 |
| 关联资源 | 链接到阅读材料或单词 |
| 核心收获 | 本次学习的关键收获 |
| 待解决问题 | 需要进一步研究的问题 |
