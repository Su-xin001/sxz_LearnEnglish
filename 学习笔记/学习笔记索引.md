## 学习统计概览

```dataview
TABLE 
  sum(rows.学习时长) as 总时长,
  sum(rows.新增单词) as 总新增,
  sum(rows.复习单词) as 总复习
FROM "学习笔记/按日期"
FLATTEN 创建日期 as 日期
GROUP BY true
```
