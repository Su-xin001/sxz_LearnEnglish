# ⌨️ 快捷键速查表

## 核心学习操作

| 快捷键 | 功能 | 使用场景 |
|--------|------|----------|
| `Ctrl+Shift+D` | 查词（Language Learner） | 选中单词后查询释义 |
| `Ctrl+Shift+T` | 翻译文本（Language Learner） | 选中句子后翻译为中文 |
| `Ctrl+Shift+A` | 添加到单词库（Language Learner） | 将选中单词加入生词本 |
| `Ctrl+Shift+E` | 英语助手查词（English Assistant） | 备用查词方式 |
| `Ctrl+Shift+W` | 添加高亮单词（Hi-Words） | 将单词加入词汇本高亮 |
| `Ctrl+Shift+S` | 文字转语音（English Learner） | 朗读选中文本 |
| `Alt+R` | 打开间隔重复复习 | 开始每日单词复习 |
| `Alt+F` | 复习当前笔记卡片 | 复习当前文件中的闪卡 |

## 模板快速插入

| 快捷键 | 模板 | 用途 |
|--------|------|------|
| `Alt+1` | 阅读文章模板 | 新建阅读笔记 |
| `Alt+2` | 单词模板 | 新建单词条目 |
| `Alt+3` | 每日记录模板 | 新建每日学习日志 |
| `Alt+4` | 语法笔记模板 | 新建语法学习笔记 |
| `Alt+5` | 写作练习模板 | 新建写作练习 |
| `Alt+6` | 复习计划模板 | 新建复习计划 |
| `Alt+7` | 听力笔记模板 | 新建听力学习笔记 |

## 导航与搜索

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Alt+N` | 新建每日记录 | 快速打开今日学习日志 |
| `Alt+G` | 打开知识图谱 | 可视化查看知识点关联 |
| `Ctrl+O` | 快速切换 | 搜索并跳转到任意文件 |
| `Ctrl+P` | 全局搜索 | 在所有文件中搜索内容 |
| `Ctrl+E` | 切换编辑/预览模式 | 在源码和阅读模式间切换 |

## 编辑操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+B` | 加粗 | 标记关键句 |
| `Ctrl+H` | 高亮 | 标记重点内容（可生成填空卡片） |
| `Ctrl+K` | 插入链接 | 创建内部链接关联知识点 |
| `Ctrl+]` | 增加缩进 | 组织层级结构 |
| `Ctrl+[` | 减少缩进 | 调整层级 |

## Obsidian 内置操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+Shift+P` | 命令面板 | 执行所有可用命令 |
| `Ctrl+N` | 新建笔记 | 创建空白笔记 |
| `Ctrl+S` | 保存文件 | 手动保存（通常自动保存） |
| `Ctrl+W` | 关闭当前标签页 | 关闭当前编辑的文件 |

## 间隔重复复习操作

| 操作 | 说明 |
|------|------|
| 点击"较难" | 记忆困难，间隔缩短 |
| 点击"记得" | 正常记忆，按算法安排 |
| 点击"简单" | 轻松记忆，间隔延长 |
| `Space` | 翻转卡片（显示答案） |

## 自定义建议

如需修改快捷键，请前往：设置 → 快捷键，搜索对应命令进行修改。

> [!tip] 记忆技巧
> - **Ctrl+Shift** 组合键 = 学习相关操作
> - **Alt+数字** = 模板快速插入
> - **Alt+字母** = 常用功能快捷入口
