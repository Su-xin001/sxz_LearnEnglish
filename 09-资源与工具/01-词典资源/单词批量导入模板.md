# 📥 单词批量导入模板

## 使用说明

将单词数据按以下格式整理后，可批量创建单词条目。
每行一个单词，字段之间用 `|` 分隔。

## 导入格式

```
单词|音标|词性|中文释义|英文释义|难度|主题|例句|例句翻译
```

## 导入步骤

1. 在上方模板中填入你的单词数据
2. 对于每个单词，在 `02-单词库/01-按字母索引/X/` 下创建文件
3. 文件名 = 单词本身
4. 复制 `10-模板/模板_单词.md` 的结构，填入对应数据
5. 设置正确的 `difficulty` 和 `topic` 属性
6. 添加 `#flashcards` 标签以启用间隔重复

## 从外部词库导入

### 从 CSV 文件导入

如果你有 CSV 格式的词库，可以按以下步骤转换：

1. 确保 CSV 包含列：word, phonetic, pos, definition_cn, definition_en, difficulty, topic
2. 使用 Obsidian 的 Templater 批量创建文件
3. 或使用 Python 脚本批量生成 Markdown 文件

### 从 Anki 导出导入

1. 在 Anki 中导出为文本格式
2. 按字段对应关系转换为本仓库格式
3. 批量创建单词条目
