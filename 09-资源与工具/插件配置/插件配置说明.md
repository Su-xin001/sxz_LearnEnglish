# 插件配置说明

## 已安装插件列表
1. **obsidian-git**: 版本控制和自动备份
2. **hi-words**: 单词高亮和管理
3. **obsidian-spaced-repetition**: 间隔重复复习系统
4. **ob-english-learner**: 英语学习工具（YouTube集成、TTS、录音等）
5. **obsidian-language-learner**: 语言学习辅助
6. **media-extended**: 媒体扩展播放
7. **rss-dashboard**: RSS订阅管理
8. **various-complements**: 自动补全和代码提示
9. **dataview**: 数据查询和可视化
10. **templater-obsidian**: 模板管理系统
11. **obsidian-calendar-plugin**: 日历视图
12. **obsidian-english-assistant**: 英语助手
13. **obsidian42-brat**: 插件测试版管理

## 插件配置详情

### hi-words配置
- **生词本路径**: `02-单词库/04-生词本`
- **字母索引路径**: `02-单词库/01-按字母索引`
- **高亮路径**: `01-阅读材料`
- **主要功能**: 单词高亮、生词收集、字母索引

### obsidian-language-learner配置
- **单词数据库**: `02-单词库/04-生词本`
- **复习数据库**: `04-复习计划/01-每日复习`
- **母语**: 中文 (zh)
- **目标语言**: 英语 (en)
- **词典配置**: 有道、剑桥、句酷、海词、DeepL
- **主要功能**: 查词、翻译、单词管理、复习计划

### ob-english-learner配置
- **视频文件夹**: `07-听力材料`
- **资源文件夹**: `07-听力材料/Assets`
- **字幕文件夹**: `07-听力材料/字幕`
- **TTS缓存**: `07-听力材料/TTS缓存`
- **录音文件夹**: `08-口语练习/录音`
- **AI提示词文件夹**: `09-资源与工具/AI提示词`
- **主要功能**: YouTube视频导入、语音识别、文本转语音、录音、AI翻译

### obsidian-spaced-repetition配置
- **排除目录**: `09-资源与工具`, `10-模板`, `11-归档`
- **闪卡标签**: `#flashcards`
- **复习标签**: `#review`
- **算法**: SM-2-OSR
- **最大间隔**: 365天
- **主要功能**: 间隔重复复习、闪卡管理、复习进度跟踪

### templater-obsidian配置
- **模板文件夹**: `10-模板`
- **文件夹模板映射**:
  - `01-阅读材料` → `模板_阅读文章`
  - `02-单词库` → `模板_单词`
  - `03-学习笔记/01-语法笔记` → `模板_语法笔记`
  - `05-每日记录` → `模板_每日记录`
  - `06-写作练习` → `模板_写作练习`
  - `04-复习计划` → `模板_复习计划`
  - `07-听力材料` → `模板_听力笔记`
- **快捷键配置**:
  - Alt+1: 插入阅读文章模板
  - Alt+2: 插入单词模板
  - Alt+3: 插入每日记录模板
- **主要功能**: 模板管理、自动应用模板、快捷键插入

### obsidian-git配置
- **自动提交间隔**: 1分钟
- **启动时自动拉取**: 启用
- **推送前拉取**: 启用
- **状态栏显示**: 启用
- **主要功能**: 自动版本控制、数据备份、同步

### dataview配置
- **查询语言**: Dataview Query Language (DQL)
- **主要功能**: 数据查询、表格生成、列表展示、进度统计

### various-complements配置
- **触发方式**: 自动提示
- **主要功能**: 代码补全、单词提示、快速输入

### media-extended配置
- **视频播放**: 支持多种格式
- **主要功能**: 视频播放控制、字幕加载、播放速度调整

### rss-dashboard配置
- **RSS源管理**: 支持多源订阅
- **主要功能**: RSS阅读、文章收藏、内容聚合

### obsidian-calendar-plugin配置
- **日历视图**: 日/周/月视图
- **主要功能**: 日程管理、笔记关联、学习计划

### obsidian-english-assistant配置
- **查词功能**: 快速查词
- **主要功能**: 英语学习辅助、单词查询、语法检查

### obsidian42-brat配置
- **测试版插件**: 管理测试版插件
- **主要功能**: 插件测试版安装、更新管理

## 故障排除
### 插件不工作
1. 检查插件是否启用
2. 重启Obsidian
3. 检查配置路径是否正确
4. 查看插件日志

### 功能异常
1. 确认目录结构正确
2. 检查模板文件是否存在
3. 验证快捷键配置
4. 更新插件到最新版本

### 性能问题
1. 减少dataview实时查询
2. 优化模板复杂度
3. 关闭不必要的插件
4. 清理缓存文件
