## 三、核心工作流

### 标准学习流程：阅读 → 收集 → 笔记 → 复习

```
1. 选择文章 ──→ 2. 深度阅读 ──→ 3. 收集生词 ──→ 4. 整理笔记 ──→ 5. 间隔复习
     │                │               │               │               │
  01-阅读材料     悬停查词        添加到单词库     03-学习笔记     04-复习计划
  按难度选择      高亮标注        Ctrl+Shift+A    阅读笔记        Alt+R 复习
                 划词翻译        Ctrl+Shift+W
```

### 工作流详解

#### 步骤1：阅读文章

1. 打开 [[00-仪表盘/英语学习仪表盘|仪表盘]]，从导航进入阅读材料区
2. 选择适合难度的文章，或通过 RSS 订阅获取新文章
3. 阅读时使用以下操作：
   - **悬停查词**：鼠标悬停单词，hi-words 自动显示释义
   - **划词翻译**：选中句子，按 `Ctrl+Shift+T` 翻译
   - **高亮标记**：用 `==高亮==` 标记重点（可生成填空卡片）
   - **加粗标记**：用 `**加粗**` 标记关键句

#### 步骤2：收集生词

1. 选中生词，按 `Ctrl+Shift+A` 添加到单词数据库
2. 或按 `Ctrl+Shift+W` 添加到 hi-words 词汇本
3. 在文章的"生词收集"表格中记录
4. 为重要单词创建独立单词条目（按 `Alt+2` 使用模板）

#### 步骤3：整理笔记

1. 在文章底部添加阅读笔记
2. 创建复习卡片（使用 `#flashcards` 标签）
3. 关联相关知识点（使用 `[[]]` 内部链接）
4. 将语法点记录到 [[03-学习笔记/01-语法笔记|语法笔记]]

#### 步骤4：间隔复习

1. 按 `Alt+R` 打开间隔重复复习
2. 按记忆情况选择"较难/记得/简单"
3. 系统基于 SM-2 算法自动安排下次复习时间
4. 在每日记录中更新复习数据

## 四、各功能模块使用说明

### 4.1 阅读功能

**支持的阅读方式：**
- 直接粘贴文章到阅读材料区
- 通过 RSS Dashboard 订阅英文源自动获取
- 通过 ob-english-learner 导入 YouTube 视频字幕
- 导入外部 Markdown/文本文件

**阅读辅助工具：**
| 功能 | 插件 | 操作 |
|------|------|------|
| 悬停释义 | hi-words | 鼠标悬停单词 |
| 词典查询 | Language Learner | Ctrl+点击/Ctrl+Shift+D |
| 划词翻译 | Language Learner | 选中→Ctrl+Shift+T |
| TTS朗读 | ob-english-learner | Ctrl+Shift+S |
| 生词高亮 | hi-words | 自动高亮词汇本中的单词 |

### 4.2 单词管理

**添加单词的方式：**
1. **快捷添加**：阅读时选中单词 → `Ctrl+Shift+A`
2. **模板创建**：`Alt+2` → 填写完整单词信息
3. **批量导入**：在生词本中按格式添加

**单词分类体系：**
- **按字母**：文件存放在 `02-单词库/01-按字母索引/X/` 下
- **按主题**：通过 `topic` 属性分类，可用 Dataview 筛选
- **按难度**：通过 `difficulty` 属性标记，支持初中到托福六级
- **交叉分类**：同一单词可同时属于多个分类（通过属性和标签实现）

**掌握度追踪：**
| 状态 | 含义 | 复习频率 |
|------|------|----------|
| 新学 | 刚学习的单词 | 次日必复习 |
| 模糊 | 记忆不牢固 | 2-3天复习 |
| 生疏 | 经常忘记 | 每天复习 |
| 已掌握 | 牢固记忆 | 一周以上复习 |

### 4.3 间隔重复复习

**复习系统：obsidian-spaced-repetition**

**卡片类型：**
1. **单行卡片**：`单词::释义`（正反面）
2. **多行卡片**：用 `?` 分隔问题和答案
3. **填空卡片**：用 `==高亮==` 标记的文本自动生成

**复习流程：**
1. 按 `Alt+R` 打开复习界面
2. 查看问题，思考答案
3. 点击显示答案
4. 根据记忆情况评分：
   - **较难**：记忆困难，间隔大幅缩短
   - **记得**：正常记忆，按算法安排
   - **简单**：轻松记忆，间隔延长

**SM-2 算法参数：**
- 基础难度：250
- 遗忘后间隔变化：×0.5
- 简单奖励：×1.3
- 最大间隔：365天

### 4.4 学习统计

**统计功能通过 Dataview 实现：**

- [[00-仪表盘/英语学习仪表盘|仪表盘]]：总览面板
- [[00-仪表盘/学习进度统计|进度统计]]：详细数据分析
- 每日记录中的 Dataview 查询：当日统计

**可追踪的指标：**
- 每日学习时长
- 新增/复习单词数量
- 掌握率变化
- 阅读量（篇数/字数）
- 词汇量增长趋势

### 4.5 写作练习

1. 按 `Alt+5` 创建写作练习
2. 使用 ob-english-learner 的 AI 批改功能
3. 记录修改建议和好词好句
4. 将错误模式记录到错题本

### 4.6 听力训练

1. 通过 ob-english-learner 导入 YouTube 视频
2. 使用双语字幕功能
3. 按 `Alt+7` 创建听力笔记
4. 使用 TTS 功能跟读练习

### 5.2 插件冲突解决方案

**问题1：hi-words 与 language-learner 悬停冲突**
- 解决：hi-words 负责已学单词高亮，language-learner 负责主动查词
- hi-words 的 `highlightPaths` 设为 `01-阅读材料`，仅在阅读区高亮

**问题2：ob-english-learner 与 english-assistant 功能重叠**
- 解决：ob-english-learner 侧重视频/音频学习，english-assistant 侧重本地词典
- 两者可共存，按需使用

## 六、常见问题排查

### Q1：Dataview 查询不显示结果
- 确认 Dataview 插件已启用
- 检查文件是否包含正确的 frontmatter 属性
- 确认文件夹路径与查询语句匹配

### Q2：间隔重复没有卡片可复习
- 确认文件包含 `#flashcards` 标签
- 检查卡片格式是否正确（`::` 或 `?` 分隔）
- 确认文件不在忽略的文件夹中

### Q3：hi-words 不高亮单词
- 确认词汇本路径正确
- 检查 `highlightPaths` 设置
- 确认单词文件名格式正确

### Q4：Language Learner 词典无法查询
- 检查网络连接（在线词典需要网络）
- 确认功能键设置（默认 Ctrl）
- 尝试切换词典优先级

### Q5：Templater 模板不生效
- 确认模板文件夹路径为 `10-模板`
- 检查文件夹模板配置
- 确认 `trigger_on_file_creation` 已开启

## 七、个性化调整建议

### 针对不同学习目标

**目标：通过四六级考试**
- 重点使用 `02-单词库/03-按难度分级/四级` 或 `六级`
- 每日复习量设为 30-50 个
- 配合 RSS 订阅考试相关文章

**目标：雅思/托福备考**
- 重点使用 `02-单词库/03-按难度分级/雅思` 或 `托福`
- 增加写作练习频率
- 利用 ob-english-learner 的 YouTube 导入功能

**目标：日常英语提升**
- 重点使用 `01-阅读材料/02-中级` 文章
- RSS 订阅 BBC/CNN 等新闻源
- 每日学习量适中，注重持续性

### 针对不同学习习惯

**视觉型学习者**
- 多使用知识图谱（`Alt+G`）查看关联
- 利用高亮和颜色分类标记
- 使用 Canvas 画布组织知识

**听觉型学习者**
- 多使用 TTS 功能（`Ctrl+Shift+S`）
- 导入 YouTube 视频进行听力训练
- 利用 ob-english-learner 的录音功能

**动手型学习者**
- 多做写作练习
- 使用填空卡片主动回忆
- 手动整理笔记和思维导图
