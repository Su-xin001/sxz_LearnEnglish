# 📋 日常学习操作手册

## 标准学习流程

每日学习按以下顺序进行，形成完整闭环：

```
┌─────────────────────────────────────────────────────────┐
│                    每日学习闭环                           │
│                                                         │
│  ① 打开每日记录 ──→ ② 阅读文章 ──→ ③ 收集生词          │
│       ↑                                    │            │
│       │                                    ↓            │
│  ⑥ 更新记录  ←── ⑤ 间隔复习  ←── ④ 整理笔记           │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

---

## ① 打开每日记录（1分钟）

### 操作步骤

1. 按 `Alt+N` 创建今日每日记录（或点击日历对应日期）
2. 模板自动填充，填写今日学习目标
3. 从 [[00-仪表盘/英语学习仪表盘|仪表盘]] 查看昨日数据和待复习项

### 每日记录模板字段说明

| 字段 | 含义 | 填写方式 |
|------|------|----------|
| study_time | 学习时长（分钟） | 学习结束时填写 |
| new_words | 新学单词数 | 自动/手动统计 |
| reviewed_words | 复习单词数 | 从复习界面获取 |
| mastery_rate | 掌握率 | 复习完成后计算 |

---

## ② 阅读文章（20-30分钟）

### 操作步骤

1. 进入 `01-阅读材料` 选择文章（或从 RSS 获取新文章）
2. 新建文章笔记：在对应难度文件夹中，按 `Alt+1` 使用阅读模板
3. 粘贴或导入英文文章到"原文"区域
4. 开始深度阅读，使用以下辅助工具：

### 阅读中的快捷操作

| 场景 | 操作 | 效果 |
|------|------|------|
| 遇到生词 | 鼠标悬停 | hi-words 自动显示释义 |
| 需要详细查词 | 选中单词 → `Ctrl+Shift+D` | Language Learner 弹出多词典结果 |
| 需要翻译句子 | 选中句子 → `Ctrl+Shift+T` | DeepL/有道翻译 |
| 标记重点 | 选中文字 → `Ctrl+H` | ==高亮标记==（可生成填空卡片） |
| 标记关键句 | 选中文字 → `Ctrl+B` | **加粗标记** |
| 听发音 | 选中文字 → `Ctrl+Shift+S` | TTS 朗读 |
| 添加到生词本 | 选中单词 → `Ctrl+Shift+A` | 加入 Language Learner 单词库 |
| 添加到高亮词 | 选中单词 → `Ctrl+Shift+W` | 加入 hi-words 词汇本 |

### 阅读后整理

1. 在"生词收集"表格中记录所有生词
2. 在"重点短语"表格中记录搭配
3. 在"难句解析"中分析复杂句子
4. 撰写中英文摘要
5. 添加阅读笔记和心得
6. 在"复习卡片"区域创建闪卡

---

## ③ 收集生词（10分钟）

### 操作步骤

1. 从阅读文章的生词表中，选择重要单词
2. 为每个重要单词创建独立条目：
   - 在 `02-单词库/01-按字母索引/X/` 下新建文件
   - 文件名即为单词本身（如 `ephemeral.md`）
   - 按 `Alt+2` 使用单词模板
3. 填写单词信息：
   - 音标、词性、释义
   - 例句（含中文翻译）
   - 词根词缀分析
   - 搭配与用法
   - 同义词/反义词
4. 设置分类属性：
   - `difficulty`: 初中/高中/四级/六级/雅思/托福
   - `topic`: 日常用语/学术词汇/商务英语/...
   - `mastery`: 新学
5. 添加复习卡片（`#flashcards` 标签）

### 单词分类规则

| 分类维度 | 属性 | 存放位置 | 示例 |
|----------|------|----------|------|
| 字母 | 文件路径 | `02-单词库/01-按字母索引/E/` | ephemeral.md |
| 主题 | `topic` 属性 | 可在任意位置 | topic: 学术词汇 |
| 难度 | `difficulty` 属性 | 可在任意位置 | difficulty: 六级 |
| 掌握度 | `mastery` 属性 | 可在任意位置 | mastery: 新学 |

---

## ④ 整理笔记（10分钟）

### 操作步骤

1. **阅读笔记**：在文章底部或 `03-学习笔记/02-阅读笔记` 中记录
2. **语法笔记**：遇到语法点，在 `03-学习笔记/01-语法笔记` 中按 `Alt+4` 创建
3. **关联知识点**：使用 `[[]]` 创建内部链接
   - 例：`学习 [[ephemeral]] 这个单词时，联想到 [[transient]]`
4. **标签分类**：使用标签进行多维度分类
   - `#阅读` `#语法` `#写作` `#听力` `#flashcards` `#review`

### 笔记关联示例

```
阅读文章 → 链接到 → 单词条目
单词条目 → 链接到 → 语法笔记
语法笔记 → 链接到 → 相关单词
每日记录 → 链接到 → 当日阅读的文章
```

## ⑤ 间隔复习（15-20分钟）

### 操作步骤

1. 按 `Alt+R` 打开间隔重复复习界面
2. 系统显示到期的复习卡片
3. 逐张复习：
   - 阅读问题/单词
   - 思考答案
   - 点击/按空格显示答案
   - 根据记忆情况评分：
     - **较难**（快捷键1）：记忆困难，间隔缩短
     - **记得**（快捷键2）：正常记忆
     - **简单**（快捷键3）：轻松记忆，间隔延长
4. 复习完成后，记录复习数据到每日记录

### 复习策略建议

| 掌握度 | 每日复习量 | 建议 |
|--------|-----------|------|
| 新学阶段 | 20-30个 | 专注近期新词 |
| 稳定阶段 | 30-50个 | 新词+旧词混合 |
| 冲刺阶段 | 50-80个 | 加大复习量 |

### 复习数据记录

在每日记录中更新：
- `reviewed_words`: 复习的单词总数
- `mastery_rate`: 掌握率 = 记得+简单 / 总复习数

---

## ⑥ 更新记录（5分钟）

### 操作步骤

1. 回到每日记录文件
2. 更新以下数据：
   - `study_time`: 今日总学习时长
   - `new_words`: 新增单词数
   - `reviewed_words`: 复习单词数
   - `mastery_rate`: 掌握率
3. 勾选已完成的目标
4. 撰写学习心得
5. 制定明日计划
6. 保存文件（自动保存 + Git 自动备份）

## 常用操作速查

### 快速添加单词（3步完成）

1. 选中单词 → `Ctrl+Shift+A`（添加到 Language Learner 词库）
2. 或 `Ctrl+Shift+W`（添加到 hi-words 词汇本）
3. 在每日记录中更新 `new_words` 计数

### 快速翻译（2步完成）

1. 选中文字
2. `Ctrl+Shift+T`（翻译）或 `Ctrl+Shift+D`（查词）

### 快速复习（2步完成）

1. `Alt+R`（打开复习界面）
2. 逐张评分

### 创建新笔记（3步完成）

1. 在目标文件夹中右键 → 新建笔记
2. Templater 自动应用对应模板
3. 填写内容

## 周度/月度维护

### 每周维护（周日进行）

1. 检查 [[00-仪表盘/学习进度统计|学习进度统计]]
2. 回顾本周学习记录，总结规律
3. 调整下周学习计划
4. 清理归档已完成的内容
5. 更新 `04-复习计划/02-每周计划`

### 每月维护

1. 分析月度学习数据
2. 调整难度级别和复习策略
3. 更新长期规划
4. 检查插件更新
5. 备份仓库（Git push）

## 典型问题排查

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| Dataview 表格为空 | 文件缺少 frontmatter | 检查并补充属性字段 |
| 闪卡不出现 | 缺少 `#flashcards` 标签 | 在文件中添加标签 |
| 高亮不生效 | 词汇本路径错误 | 检查 hi-words 设置 |
| 翻译无响应 | 网络问题 | 检查网络，切换词典 |
| 模板不触发 | Templater 未启用 | 检查插件状态和配置 |
| 复习数据丢失 | dataStore 设置 | 确认为 "NOTES" 模式 |
