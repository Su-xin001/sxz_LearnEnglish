## 规则说明

虚拟语气（Subjunctive Mood）用来表示说话人的愿望、假设、猜测或建议，而不是客观存在的事实。

## 结构公式

**与现在事实相反**：If + 主语 + 过去式, 主语 + would/could/might + 动词原形  
**与过去事实相反**：If + 主语 + had + 过去分词, 主语 + would/could/might + have + 过去分词  
**与将来事实相反**：If + 主语 + were to/should + 动词原形, 主语 + would/could/might + 动词原形

## 例句

### 与现在事实相反

1. If I **were** you, I **would study** harder.
2. If she **had** more time, she **could travel** the world.
3. If it **were** not raining, we **would go** outside.

### 与过去事实相反

1. If I **had known** the truth, I **would have acted** differently.
2. If she **had studied** harder, she **could have passed** the exam.
3. If they **had left** earlier, they **would have caught** the train.

### 与将来事实相反

1. If it **should rain** tomorrow, we **would cancel** the trip.
2. If I **were to win** the lottery, I **would buy** a house.

## 常见错误

1. ❌ If I was you... → ✅ If I **were** you...（虚拟语气中 be 动词一律用 were）
2. ❌ If I would have known... → ✅ If I **had** known...（if 从句不用 would）
3. ❌ I wish I can fly. → ✅ I wish I **could** fly.（wish 后用虚拟语气）

## 练习

1. If I _____ (be) rich, I would buy a yacht.
2. If she _____ (study) harder, she would have passed.
3. I wish I _____ (know) the answer.

## 单词卡片

虚拟语气::表示与事实相反的假设或愿望，be动词一律用were
