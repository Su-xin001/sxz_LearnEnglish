## ⚙️ 核心插件详细配置

### 1. Spaced Repetition（间隔重复）

#### 基础配置
```json
{
  "flashcardTags": ["#flashcards"],
  "singleLineCardSeparator": "::",
  "singleLineReversedCardSeparator": ":::",
  "multilineCardSeparator": "?",
  "multilineReversedCardSeparator": "??",
  "algorithm": "SM-2-OSR",
  "baseEase": 250,
  "easyBonus": 1.3,
  "lapsesIntervalChange": 0.5
}
```

#### 卡片格式说明

**单线卡片（正面::背面）**
```
单词 (词性)::/音标/ 中文释义
```

**多线卡片**
```
单词 (词性)
?
/音标/
中文释义
例句
```

**双向卡片（可翻转）**
```
单词:::中文释义
```

#### 快捷键
- `Ctrl+Alt+S`：开始复习闪卡
- `Ctrl+Alt+R`：查看复习队列

---

### 2. HiWords（智能词汇管理）

#### 配置参数
```json
{
  "vocabularyBooks": [
    {
      "path": "02-单词库/单词总库.canvas",
      "name": "单词总库",
      "enabled": true
    }
  ],
  "showDefinitionOnHover": true,
  "enableAutoHighlight": true,
  "highlightStyle": "underline",
  "enableMasteredFeature": true,
  "blurDefinitions": false,
  "ttsTemplate": "https://dict.youdao.com/dictvoice?audio={{word}}&type=2"
}
```

#### 功能特性
- ✅ 自动高亮单词库中的词汇
- ✅ 鼠标悬停显示释义
- ✅ 支持TTS发音
- ✅ 掌握程度标记
- ✅ 侧边栏词汇列表

#### 使用方法
1. 将单词添加到单词总库 Canvas
2. 在阅读文章中自动高亮
3. 鼠标悬停查看释义
4. 点击标记掌握状态

#### 模板文件夹
- 路径：`06-模板库/`

2. **单词卡片模板** - 用于创建单词笔记

### 5. Dataview（数据查询）

#### 使用场景
- 学习数据统计
- 单词列表展示
- 阅读进度跟踪
- 复习计划管理

#### 常用查询示例

**查询所有单词**
```dataview
TABLE word, phonetic, part_of_speech, difficulty
FROM "02-单词库"
SORT date_added DESC
```

**查询今日学习**
```dataview
TABLE date, new_words, review_words
FROM "03-学习笔记/01-每日笔记"
WHERE date = date(today)
```

## 🔧 插件冲突排查

### 已知兼容性问题

| 插件组合 | 状态 | 解决方案 |
|----------|------|----------|
| HiWords + Language Learner | ✅ 兼容 | 正常同时使用 |
| Spaced Repetition + Dataview | ✅ 兼容 | 正常同时使用 |
| English Assistant + English Learner | ⚠️ 注意 | 避免功能重复 |

### 性能优化建议

1. **减少同时启用的插件数量**
   - 仅启用当前需要的插件
   - 定期清理不用的插件

2. **优化大型文件处理**
   - 单词库文件过大时分割存储
   - 定期归档历史数据

3. **定期重启Obsidian**
   - 释放内存
   - 刷新插件状态

## 🆘 常见问题解决

### 问题1：Spaced Repetition 无法识别卡片

**原因**：标签或分隔符配置错误

**解决**：
1. 检查文件是否包含 `#flashcards` 标签
2. 确认使用正确的分隔符 `::` 或 `?`
3. 重新加载插件

### 问题2：HiWords 不显示高亮

**原因**：词汇库路径配置错误

**解决**：
1. 检查词汇库 Canvas 文件路径
2. 确认单词已添加到 Canvas
3. 重新启用自动高亮

### 问题3：Dataview 查询无结果

**原因**：文件元数据格式错误

**解决**：
1. 检查 YAML 前置元数据格式
2. 确认字段名称正确
3. 使用 Dataview 调试模式
