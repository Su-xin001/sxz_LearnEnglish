# 📊 学习统计面板

## 总体概览

```dataview
TABLE 
  length(rows) as 总笔记数
FROM ""
WHERE 创建日期
GROUP BY true
```

## 单词掌握统计

```dataview
TABLE length(rows) as 数量
FROM "单词库"
WHERE 单词
FLATTEN 掌握程度 as 程度
GROUP BY 程度
```

## 阅读进度统计

```dataview
TABLE length(rows) as 数量
FROM "阅读材料"
WHERE 阅读状态
FLATTEN 阅读状态 as 状态
GROUP BY 状态
```

## 近7天学习记录

```dataview
TABLE 学习时长, 新增单词, 复习单词, 掌握率
FROM "学习笔记/按日期"
SORT 创建日期 DESC
LIMIT 7
```

## 单词难度分布

```dataview
TABLE length(rows) as 数量
FROM "单词库"
WHERE 难度等级
FLATTEN 难度等级 as 难度
GROUP BY 难度
```

## 阅读难度分布

```dataview
TABLE length(rows) as 数量
FROM "阅读材料"
WHERE 难度等级
FLATTEN 难度等级 as 难度
GROUP BY 难度
```

## 复习完成率

```dataview
TABLE 
  length(rows) as 总计划数,
  length(filter(rows, (r) => r.状态 = "已完成")) as 已完成数
FROM "复习计划"
GROUP BY true
```

## 月度学习趋势

```dataview
TABLE 
  sum(rows.新增单词) as 月新增单词,
  sum(rows.复习单词) as 月复习单词,
  sum(rows.学习时长) as 月学习时长
FROM "学习笔记/按日期"
FLATTEN 创建日期 as 日期
GROUP BY true
```
