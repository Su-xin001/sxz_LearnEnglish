## 二、MCP 服务器（AI 读写仓库的桥梁）

| 工具 | 用途 | 状态 | 优先级 |
|---|---|---|---|
| **obsidian-mcp** | 本地 MCP 服务器，让 AI 安全地读/写/搜索你的笔记库（增删改查、全文搜索、标签管理、移动），无需打开 Obsidian；事务回滚与回收机制 | 已验证（721★，v2 活跃维护） | ⭐ 核心 |
| **DeepL MCP**（`deepl-mcp-server`） | DeepL 官方翻译 MCP，高质量翻译 | 已验证（官方维护，需付费 API key） | 🔹 可选 |
| 词典类 MCP（cambridge-dict、yomitan 等） | 词典查询 | 生态早期，均为低 star 个人项目 | ⏸ 建议暂缓 |

### obsidian-mcp 配置要点（本仓库）

- 环境要求：Node.js 22+
- 启动命令：
  ```
  npx -y obsidian-mcp@2 serve --vault notes=D:/GitHub/sxz_LearnEnglish
  ```
- 在 MCP 客户端（如 Reasonix / Claude Desktop）的 `mcpServers` 中配置：
  ```json
  {
    "mcpServers": {
      "obsidian": {
        "command": "npx",
        "args": ["-y", "obsidian-mcp@2", "serve", "--vault", "notes=D:/GitHub/sxz_LearnEnglish"]
      }
    }
  }
  ```
- 安全机制：vault 路径启动时白名单授权；路径校验防越权；变更走事务（`.obsidian-mcp/transactions`，默认保留 30 天可回滚）；删除默认进回收站（`.obsidian-mcp/trash`）
- 注意：`notes=` 是 vault 的 id（可自定义），`D:/GitHub/sxz_LearnEnglish` 是该仓库的绝对路径

## 四、AI 深度参与工作流（推荐日常用法）

```
阅读/听写中遇到生词
        │
        ▼
① AI 查词（模型原生 + Obsidian Dictionary）
        │
        ▼
② AI 生成单词卡片：单词 / 音标 / 释义 / 词根词缀 / 2-3 个地道例句
        │   （写入时标注 #flashcards/词汇 分层标签）
        ▼
③ obsidian-mcp 写入仓库词汇区（create/edit 笔记）
        │
        ▼
④ Spaced Repetition 按 FSRS 算法安排每日复习
        │
        ▼
⑤ 每日笔记中 AI 汇总：今日新词、待复习词、易错词
        │
        ├──▶ 生成新例句 / 主题写作练习
        └──▶ 作文批改：AI 读取作文 → 语法/用词/结构批改 → 写回并沉淀句式卡片
```

## 五、建议安装顺序

1. **第一批（必装底座）**：Spaced Repetition、Obsidian Git、Templater、Dataview、QuickAdd

5. 参考 obsidian-vault skill 约定规划笔记结构（后续搭建阶段执行）
