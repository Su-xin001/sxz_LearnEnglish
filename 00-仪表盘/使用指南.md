# 📋 使用指南

## 目录结构

| 目录 | 用途 |
|---|---|
| `00-仪表盘/` | 学习中心（统计仪表盘）、使用指南、工具清单 |
| `01-词汇/` | 单词库，按难度分层（CET4核心/CET6核心/考研词汇/雅思托福/其他） |
| `02-阅读/` | 阅读材料与精读笔记 |
| `03-写作/` | 写作练习与 AI 批改记录 |
| `04-听力口语/` | 听力精听与口语笔记 |
| `05-模板与资源/` | 6 个模板 + 图片/音频/导入资源 |
| `06-每日记录/` | Daily notes 学习日记 |
| `99-归档/` | 已完成内容 |

## 快捷键

- `Ctrl+P`：命令面板（所有操作入口）
- `Ctrl+N` / 命令面板 "Templates: Insert template"：插入模板
- 命令面板 "Open today's daily note"：创建/打开今日学习记录（模板自动套用每日学习模板）

## 插件安装清单

在 Obsidian 设置 → 第三方插件 → 关闭安全模式 → 浏览社区插件市场，搜索并安装：

**必装**

| 插件 | 商店搜索名 | 用途 |
|---|---|---|
| Spaced Repetition | `Spaced Repetition` | 单词卡/整篇笔记间隔重复复习（识别 `#flashcards/<牌组>` 标签） |
| Obsidian Git | `Obsidian Git` | 自动备份与版本同步（仓库已配置 .gitignore） |

**推荐**

| 插件 | 商店搜索名 | 用途 |
|---|---|---|
| Dataview | `Dataview` | 学习中心与各索引页的统计/聚合（未装则索引页不渲染） |
| Templater | `Templater` | 模板引擎（可选，核心模板功能已够用） |
| QuickAdd | `QuickAdd` | 快速捕获/一键新建笔记 |
| Obsidian Dictionary | `Obsidian Dictionary` | 查词：释义、音标、同义词，可生成词典笔记 |
| Edge TTS | `Edge TTS` | 免费高质量朗读（单词/句子发音） |

**可选**：Yanki（需 Anki 桌面端）、Readwise Official（付费订阅）、Whisper 语音转写。

## 划词翻译（immersive-translate）

- 已安装 **immersive-translate**（沉浸式翻译）：选中文本即时翻译、段落/整页双语对照
- 首次使用：到 [immersive-translate.com](https://immersive-translate.com) 免费注册获取 API key → 插件设置 → 填入 API key（key 仅保存在本地 `data.json`，不会提交到 git）
- 用法：选中英文文本 → 翻译悬浮窗；侧边栏可整页双语对照

## AI 对话（Copilot）

- 已安装 **Copilot**（Obsidian 内 AI 对话），已预置 DeepSeek 模型（`deepseek-chat`）
- API key 已配置在本地 `data.json`（git 已忽略该文件）；若需更换，在 Copilot 设置 → API Keys 中填写
- 用法：侧边栏 Copilot 面板直接对话——查词、解释语法、批改作文、生成例句

## PDF 标注（Annotator）

- 已安装 **Annotator**：打开 PDF/EPUB 直接标注（高亮、批注），标注保存为独立笔记
- 用法：命令面板 "Annotator: Open" 选择 PDF（如真题 PDF）→ 标注 → 笔记与原文互链

## 网页剪藏（Obsidian Web Clipper）

- 浏览器扩展（Obsidian 官方，非社区插件）：Chrome/Edge 应用商店搜索 "Obsidian Web Clipper" 安装
- 配置：扩展设置 → 登录 Obsidian 账号或填写本地 vault 路径 → 选择剪藏目标文件夹（建议 `02-阅读/`）
- 用法：浏览外刊/文章时点击扩展图标 → 一键剪藏为 Markdown 入仓库

## 学习图表（Obsidian Charts）

- 已安装 **Obsidian Charts**：用代码块把数据可视化为柱状/饼图
- 学习中心已含按难度分布的图表示例；数据源可改为 Dataview 查询结果

## AI 用法

仓库配置了 **obsidian-mcp**（本地 MCP 服务器），AI 可直接读写笔记库：

- **查词建卡**：告诉 AI "把 resilient 做成单词卡" → AI 生成完整卡片写入 `01-词汇/雅思托福/resilient.md` 并打 `#flashcards/雅思托福` 标签 → Spaced Repetition 自动纳入复习
- **作文批改**：把作文粘贴到 `03-写作/` 新笔记 → 让 AI "批改这篇作文" → AI 写回 `ai_review` 字段与修改建议
- **每日总结**：让 AI "总结今天的学习" → 汇总新词/复习/写作情况

AI 行为规范见仓库根目录 `REASONIX.md`。
