## 二、插件列表与配置

### 核心学习插件

| 插件 | 功能 | 关键配置 |
| ---- | ---- | -------- |
| **obsidian-spaced-repetition** | 间隔重复复习 | 标签: `#flashcards`；复习标签: `#review`, `#单词`, `#语法`；中文按钮；最大间隔365天 |
| **obsidian-language-learner** | 划词翻译、查词 | 母语: zh；外语: en；词典: 有道→剑桥→句酷→沪江→DeepL；自动发音；机器翻译 |
| **obsidian-english-assistant** | AI英语助手 | 本地词典优先；写作批改；TTS发音；签到追踪 |
| **hi-words** | 单词高亮与悬停释义 | 悬停显示释义；自动高亮；掌握标记；有道TTS |
| **dataview** | 数据查询与统计 | 启用JS查询；启用内联查询；刷新间隔2.5秒 |
| **templater-obsidian** | 模板系统 | 模板文件夹: `模板/`；文件夹自动模板；热键模板 |
| **obsidian-calendar-plugin** | 日历视图 | 日记文件夹: `07-日记/`；模板: `模板/模板-学习日记` |

### Callout使用示例

```markdown
> [!vocab] 单词
> elaborate — 精心制作的；详细阐述

> [!grammar] 语法点
> 现在完成时：have/has + 过去分词

> [!pronunciation] 发音提示
> 注意连读：put it on → pu-ti-ton

> [!example] 例句
> She made elaborate preparations for the party.

> [!translation] 翻译
> 她为派对做了精心的准备。

> [!tip-en] 学习建议
> 每天坚持复习，间隔重复效果最佳。

> [!warning-en] 易错点
> elaborate 作动词时重音在第二音节。
```

## 六、单词学习系统

### 单词卡Frontmatter字段说明

| 字段 | 类型 | 说明 | 可选值 |
| ---- | ---- | ---- | ------ |
| 单词 | text | 英文单词 | - |
| 音标 | text | 国际音标 | - |
| 词性 | text | 词性 | 名词/动词/形容词/副词/介词/连词等 |
| 释义 | text | 中文释义 | - |
| 难度 | text | 难度等级 | 初级/中级/高级 |

| 记忆阶段 | text | 当前记忆阶段 | 新学/学习中/需复习/已掌握 |
| 添加日期 | date | 添加日期 | YYYY-MM-DD |
| 复习次数 | number | 已复习次数 | - |
| 上次复习 | date | 上次复习日期 | YYYY-MM-DD |
| 下次复习 | date | 下次复习日期 | YYYY-MM-DD |
| 来源 | text | 学习来源 | 四级真题/阅读文章/听力等 |

### 间隔重复复习

使用 `#flashcards` 标签标记的单词会自动出现在间隔重复复习中：
- 单行格式：`单词::释义`
- 多行格式：使用 `?` 分隔
- 填空格式：`==答案==` 高亮部分为挖空

## 七、阅读学习系统

### 悬停查词

在阅读英文文章时：
1. 按住 `Ctrl` 键 + 鼠标悬停单词 → Language Learner 弹出词典
2. Hi-Words 会自动在已学单词下划线显示释义

### 划词翻译

选中英文文本后，使用 Language Learner 插件进行翻译。

### 高亮标记

使用 `==高亮文本==` 标记重点内容，高亮内容同时会作为间隔重复的填空题。

## 八、日常学习流程

### 每日流程

1. **打开仪表盘** — 查看今日待复习和学习统计
2. **复习单词** — `Alt+R` 开始间隔重复复习
3. **学习新单词** — `Alt+1` 创建新单词卡
4. **阅读文章** — `Alt+2` 创建阅读笔记，粘贴文章
5. **听力练习** — `Alt+3` 创建听力笔记
6. **记录日记** — `Alt+J` 打开今日学习日记
7. **提交备份** — Git自动备份，手动 `Ctrl+Alt+U` 推送

### 每周流程

1. **口语练习** — 至少2次口语练习记录
2. **写作练习** — 至少1篇写作练习
3. **语法整理** — 整理本周遇到的语法点
4. **知识图谱** — `Alt+G` 查看知识点关联
5. **回顾总结** — 在日记中总结本周学习

## 九、文件命名规范

- **单词卡**：直接使用英文单词作为文件名（如 `elaborate.md`）
- **阅读笔记**：`阅读-文章标题.md`（如 `阅读-The Future of AI.md`）
- **听力笔记**：`听力-材料名称.md`（如 `听力-TED-How to Learn.md`）
- **口语练习**：`口语-话题.md`（如 `口语-自我介绍.md`）
- **语法笔记**：`语法-语法点名称.md`（如 `语法-现在完成时.md`）
- **写作练习**：`写作-题目.md`（如 `写作-科技与生活.md`）
- **学习日记**：`YYYY-MM-DD.md`（如 `2026-04-16.md`）
