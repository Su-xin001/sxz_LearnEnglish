## 📊 单词库总览（按难度）

> 下方图表为静态示例数据（Obsidian Charts 插件渲染）；实际数量以上面 Dataview 查询为准，可改为 Dataview 数据源。

```charts
type: bar
title: 单词难度分布（示例）
x: CET4, CET6, 考研, 雅思托福, 其他
y: [2, 1, 1, 1, 1]
```

```dataview
TABLE length(rows) AS "单词数"
FROM "01-词汇"
WHERE contains(tags, "单词")
GROUP BY difficulty
```

## 🆕 最近 7 天新增单词

```dataview
TABLE file.ctime AS "创建时间"
FROM "01-词汇"
WHERE contains(tags, "单词") AND file.ctime >= date(today) - dur(7 days)
SORT file.ctime DESC
```
