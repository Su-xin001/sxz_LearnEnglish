## ⚡ 快速操作

| 操作         | 快捷方式              | 说明           |
| ---------- | ----------------- | ------------ |
| 📝 快速添加单词  | `Ctrl+Shift+W`    | 弹出添加单词对话框    |
| ✅ 从选中文本添加  | `Ctrl+Shift+A`    | 选中单词后一键添加    |
| 🏷️ 管理单词分类 | `Ctrl+Shift+C`    | 修改当前单词的所有分类  |
| 🔖 快捷添加分类  | `Ctrl+Shift+T`    | 一键切换分类标签     |
| 📥 批量导入CSV | `Ctrl+P` → "批量导入" | 从CSV文件批量导入单词 |
| 🗂️ 浏览分类视图 | `Ctrl+P` → "浏览分类" | 按分类浏览所有单词    |
| 📦 批量分类管理  | `Ctrl+P` → "批量分类" | 批量修改多个单词分类   |
| 🔄 开始复习    | `Ctrl+Shift+R`    | 启动间隔重复复习     |
| 🔍 查词      | `Ctrl+鼠标悬停`       | 即时查词翻译       |
| 📅 打开今日日记  | `Alt+T`           | 打开/创建今天的日记   |
| 🖱️ 右键添加   | 选中单词→右键           | 添加到单词库/快速查词  |

## 📊 学习数据总览

```dataviewjs
const wordCount = dv.pages('"01-单词库"').where(p => p.word).length;
const todayWords = dv.pages('"01-单词库"').where(p => {
    if (!p.word || !p.date_added) return false;
    const added = dv.date(p.date_added);
    return added && added.hasSame(dv.date("today"), "day");
}).length;
const readCount = dv.pages('"02-阅读材料"').where(p => p.date_read).length;
const writeCount = dv.pages('"04-写作练习"').where(p => p.date).length;

const stats = [
    { icon: "📚", title: "单词总量", value: wordCount, label: "已收录单词", color: "purple" },
    { icon: "🆕", title: "今日新词", value: todayWords, label: "今日新增", color: "green" },
    { icon: "📖", title: "阅读篇数", value: readCount, label: "已阅读文章", color: "blue" },
    { icon: "✍️", title: "写作练习", value: writeCount, label: "写作练习数", color: "orange" }
];

const grid = dv.el("div", "", { cls: "dashboard-grid" });

for (const stat of stats) {
    const card = grid.createEl("div", { cls: `dashboard-card stat-card stat-card-${stat.color}` });
    card.createEl("h3", { text: `${stat.icon} ${stat.title}` });
    const statDiv = card.createEl("div", { cls: "dashboard-stat" });
    statDiv.createEl("div", { text: String(stat.value), cls: "stat-number" });
    statDiv.createEl("div", { text: stat.label, cls: "stat-label" });
}
```

## 📈 单词掌握度分布

```dataview
TABLE 
  length(rows) as 数量,
  length(filter(rows, (r) => r.mastery >= 4)) as "已掌握",
  length(filter(rows, (r) => r.mastery >= 2 AND r.mastery < 4)) as "学习中",
  length(filter(rows, (r) => r.mastery < 2)) as "新词"
FROM "01-单词库"
WHERE word
FLATTEN 1 as count
GROUP BY true
```

## 📋 待复习单词

```dataview
TABLE 
  word AS "单词",
  phonetic_us AS "音标",
  difficulty AS "难度",
  mastery AS "掌握度"
FROM "01-单词库"
WHERE word AND mastery < 3
SORT mastery ASC, date_added ASC
LIMIT 15
```
