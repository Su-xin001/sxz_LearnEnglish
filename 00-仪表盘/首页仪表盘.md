## 📖 单词掌握情况

### 按难度分布

```dataview
TABLE difficulty AS 难度, mastery AS 掌握程度, date AS 添加日期
FROM "01-单词库"
WHERE word
SORT date DESC
```

### 按掌握程度统计

```dataview
TABLE length(rows) AS 数量
FROM "01-单词库"
WHERE word
GROUP BY mastery AS 掌握程度
SORT mastery ASC
```

### 待复习单词

```dataview
LIST
FROM "01-单词库"
WHERE mastery = "陌生" OR mastery = "熟悉"
SORT date DESC
LIMIT 10
```
