# 📊 学习统计

## 单词学习进度

### 按难度分布

```dataview
TABLE 
  length(rows) as 总数,
  length(filter(rows, (r) => r.mastery >= 4)) as 已掌握,
  length(filter(rows, (r) => r.mastery >= 2 AND r.mastery < 4)) as 学习中,
  length(filter(rows, (r) => r.mastery < 2)) as 新词
FROM "01-单词库"
WHERE word
GROUP BY difficulty
SORT difficulty ASC
```

### 按记忆阶段分布

```dataview
TABLE 
  length(rows) as 数量
FROM "01-单词库"
WHERE word
GROUP BY memory_stage
SORT length(rows) DESC
```

### 掌握度趋势

```dataview
TABLE 
  date_added AS "添加日期",
  length(rows) AS "当日新增"
FROM "01-单词库"
WHERE word AND date_added
GROUP BY date_added
SORT date_added DESC
LIMIT 14
```

## 阅读进度

### 按难度分布

```dataview
TABLE 
  length(rows) as 篇数
FROM "02-阅读材料"
WHERE date_read
GROUP BY difficulty
```

### 按状态分布

```dataview
TABLE 
  length(rows) as 篇数
FROM "02-阅读材料"
WHERE date_read
GROUP BY status
```

### 最近阅读记录

```dataview
TABLE 
  title AS "标题",
  source AS "来源",
  difficulty AS "难度",
  date_read AS "日期"
FROM "02-阅读材料"
WHERE date_read
SORT date_read DESC
LIMIT 10
```

## 写作练习统计

```dataview
TABLE 
  title AS "标题",
  type AS "类型",
  date AS "日期",
  score AS "评分"
FROM "04-写作练习"
WHERE date
SORT date DESC
```

## 语法学习进度

```dataview
TABLE 
  title AS "语法点",
  category AS "分类",
  difficulty AS "难度"
FROM "03-语法笔记"
SORT difficulty ASC
```

## 综合学习数据

```dataview
TABLE 
  length(filter(rows, (r) => r.word)) AS "单词数",
  length(filter(rows, (r) => r.date_read)) AS "阅读数"
FROM "01-单词库" OR "02-阅读材料"
FLATTEN 1 as count
GROUP BY true
```
