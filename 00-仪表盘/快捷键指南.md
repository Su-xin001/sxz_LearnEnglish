# ⌨️ 快捷键指南

## 核心快捷键

### Obsidian 原生

| 快捷键            | 功能      | 说明          |
| -------------- | ------- | ----------- |
| `Ctrl+P`       | 命令面板    | 执行所有命令的入口   |
| `Ctrl+O`       | 快速切换    | 搜索并打开笔记     |
| `Ctrl+N`       | 新建笔记    | 创建空白笔记      |
| `Ctrl+E`       | 切换编辑/预览 | 在编辑和阅读模式间切换 |
| `Ctrl+Shift+F` | 全局搜索    | 在整个仓库中搜索    |
| `Ctrl+G`       | 图谱视图    | 查看知识图谱      |
| `Ctrl+[`       | 返回      | 返回上一个位置     |
| `Ctrl+]`       | 前进      | 前进到下一个位置     |
| `Alt+T`        | 打开今日日记  | 打开/创建今天的日记  |

### Word Manager 单词管理

| 快捷键                  | 功能      | 说明           |
| -------------------- | ------- | ------------ |
| `Ctrl+Shift+W`       | 快速添加单词  | 弹出添加单词对话框    |
| `Ctrl+Shift+A`       | 从选中文本添加 | 选中单词后一键添加    |
| `Ctrl+Shift+C`       | 管理单词分类  | 修改当前单词的所有分类  |
| `Ctrl+Shift+T`       | 快捷添加分类  | 一键切换分类标签     |
| `Ctrl+P` → "批量导入CSV" | 批量导入    | 从CSV文件批量导入单词 |
| `Ctrl+P` → "浏览分类视图"  | 分类浏览    | 按分类浏览所有单词    |
| `Ctrl+P` → "批量分类管理"  | 批量分类    | 批量修改多个单词分类   |

### 学习辅助

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+Shift+R` | 开始复习 | 启动间隔重复复习 |
| `Ctrl+Shift+L` | 划词查词 | language-learner 即时查词 |
| `Ctrl+Alt+T` | 插入模板 | Templater 插入模板 |
| `Ctrl+Alt+N` | 从模板创建 | Templater 从模板创建笔记 |

### 阅读辅助

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+鼠标悬停` | 划词翻译 | 查看单词详细释义 |
| 选中文字 → `右键` | 高亮/批注 | 添加高亮标记或批注 |
| `Ctrl+P` → "阅读笔记" | 新建阅读笔记 | 使用模板创建阅读笔记 |

### 格式化

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+B` | 加粗 | **加粗文字** |
| `Ctrl+I` | 斜体 | *斜体文字* |
| `Ctrl+H` | 高亮 | ==高亮文字== |
| `Ctrl+K` | 插入链接 | [链接文字](URL) |
| `Ctrl+[[]]` | 插入内部链接 | [[笔记名称]] |
| `Ctrl+Shift+M` | 引用块 | > 引用文字 |

## Templater 快速创建

在命令面板（`Ctrl+P`）中输入以下关键词快速创建：

- `单词卡片` → 创建标准单词卡片
- `阅读笔记` → 创建阅读笔记
- `语法笔记` → 创建语法笔记
- `写作练习` → 创建写作练习
- `每日学习` → 创建每日学习日志
- `学习日志` → 创建独立学习日志
- `听力笔记` → 创建听力笔记

## 右键菜单

| 位置 | 操作 | 说明 |
|------|------|------|
| 编辑器 → 选中英文单词 | 添加到单词库 | 快速添加选中的单词 |
| 编辑器 → 选中英文单词 | 快速查词 | 打开有道词典查询 |
| 文件管理器 → 单词文件 | 管理单词分类 | 打开分类管理弹窗 |
| 文件管理器 → 单词文件 | 快捷添加分类 | 一键切换分类标签 |
