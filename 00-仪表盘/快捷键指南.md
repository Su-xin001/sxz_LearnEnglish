# ⌨️ 快捷键指南

## 核心快捷键

### Obsidian 原生

| 快捷键            | 功能      | 说明          |
| -------------- | ------- | ----------- |
| `Ctrl+P`       | 命令面板    | 执行所有命令的入口   |
| `Ctrl+O`       | 快速切换    | 搜索并打开笔记     |
| `Ctrl+N`       | 新建笔记    | 创建空白笔记      |
| `Ctrl+E`       | 切换编辑/预览 | 在编辑和阅读模式间切换 |
| `Ctrl+Shift+F` | 全局搜索    | 在整个仓库中搜索    |
| `Ctrl+G`       | 图谱视图    | 查看知识图谱      |
| `Ctrl+[`       | 返回      | 返回上一个位置     |
| `Ctrl+]`       | 前进      | 前进到下一个位置    |
| `Alt+T`        | 打开今日日记  | 打开/创建今天的日记  |

### 单词学习

| 快捷键                     | 功能   | 说明                    |
| ----------------------- | ---- | --------------------- |
| `Ctrl+鼠标悬停`             | 即时查词 | language-learner 划词翻译 |
| `Ctrl+P → "SR: Review"` | 开始复习 | 启动间隔重复复习              |
| `Ctrl+P → "单词卡片"`       | 新建单词 | 使用模板创建单词卡片            |

### 阅读辅助

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+鼠标悬停` | 划词翻译 | 查看单词详细释义 |
| 选中文字 → `右键` | 高亮/批注 | 添加高亮标记或批注 |
| `Ctrl+P → "阅读笔记"` | 新建阅读笔记 | 使用模板创建阅读笔记 |

### 格式化

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+B` | 加粗 | **加粗文字** |
| `Ctrl+I` | 斜体 | *斜体文字* |
| `Ctrl+H` | 高亮 | ==高亮文字== |
| `Ctrl+K` | 插入链接 | [链接文字](URL) |
| `Ctrl+[[]]` | 插入内部链接 | [[笔记名称]] |
| `Ctrl+Shift+M` | 引用块 | > 引用文字 |

## 自定义快捷键建议

在 Obsidian 设置 → 快捷键 中配置以下快捷键：

| 命令 | 建议快捷键 | 说明 |
|------|-----------|------|
| SR: Review flashcards | `Ctrl+Shift+R` | 快速启动复习 |
| Language Learner: Lookup | `Ctrl+Shift+L` | 快速查词 |
| English Assistant: Check writing | `Ctrl+Shift+W` | AI写作批改 |
| Templater: Create note from template | `Ctrl+Shift+T` | 从模板创建 |
| Hi-Words: Toggle highlight | `Ctrl+Shift+H` | 切换高亮 |

## Templater 快速创建

在命令面板（`Ctrl+P`）中输入以下关键词快速创建：

- `单词卡片` → 创建标准单词卡片
- `阅读笔记` → 创建阅读笔记
- `语法笔记` → 创建语法笔记
- `写作练习` → 创建写作练习
- `每日学习` → 创建每日学习日志
- `听力笔记` → 创建听力笔记
