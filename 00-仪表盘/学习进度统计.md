# 📊 学习进度统计

## 总体概览

```dataview
TABLE length(rows) AS "总数"
FROM "02-单词库"
FLATTEN mastery AS 掌握程度
GROUP BY 掌握程度
SORT 掌握程度 ASC
```

## 词汇量增长趋势

```dataview
TABLE length(rows) AS "新增单词数"
FROM "02-单词库"
WHERE date >= date(today) - dur(30 days)
GROUP BY dateformat(file.ctime, "yyyy-MM-dd") AS 日期
SORT 日期 DESC
LIMIT 30
```

## 阅读量统计

```dataview
TABLE length(rows) AS "文章数", sum(default(word_count, 0)) AS "总字数"
FROM "01-阅读材料"
WHERE date >= date(today) - dur(30 days)
GROUP BY dateformat(date, "yyyy-MM-dd") AS 日期
SORT 日期 DESC
LIMIT 30
```

## 掌握度分析

### 需要加强的单词

```dataview
TABLE phonetic AS "音标", pos AS "词性", difficulty AS "难度", review_count AS "复习次数"
FROM "02-单词库"
WHERE mastery = "生疏" OR mastery = "模糊"
SORT review_count ASC, difficulty DESC
LIMIT 20
```

### 已掌握的单词

```dataview
TABLE phonetic AS "音标", pos AS "词性", difficulty AS "难度"
FROM "02-单词库"
WHERE mastery = "已掌握"
SORT difficulty DESC
LIMIT 20
```

## 每日学习时长

```dataview
TABLE study_time AS "⏱时长(分)", new_words AS "📝新词", reviewed_words AS "🔄复习", mastery_rate AS "📈掌握率"
FROM "05-每日记录"
WHERE date >= date(today) - dur(14 days)
SORT date DESC
```

## 复习效果追踪

```dataview
TABLE mastery_rate AS "掌握率", reviewed_words AS "复习数", new_words AS "新词数"
FROM "05-每日记录"
```
