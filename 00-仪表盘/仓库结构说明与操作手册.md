## 日常操作手册

### 📝 添加新单词

**方法一：使用模板（推荐）**
1. `Ctrl+P` → 输入 "Templater"
2. 选择 "单词卡片模板"
3. 输入单词作为标题
4. 填写音标、释义、例句等信息
5. 将笔记移动到对应难度文件夹

**方法二：划词添加**
1. 在阅读材料中选中单词
2. `Ctrl+鼠标悬停` 查看释义
3. 在弹窗中点击保存到生词本

**方法三：批量导入**
1. 准备CSV文件（格式参考「单词库主页 → CSV导入说明」）
2. 将CSV放入 `08-资源/导入` 文件夹
3. `Ctrl+P` → 运行 "批量导入CSV单词" 命令

### 📖 阅读英文文章

**步骤**：
1. `Ctrl+P` → 选择 "阅读笔记模板"
2. 粘贴英文原文到"原文"区域
3. 使用高亮标注标记内容：
   - `<span class="highlight-pink">生词</span>` — 粉色标记生词
   - `<span class="highlight-orange">好句</span>` — 橙色标记好句
   - `<span class="highlight-yellow">重点</span>` — 黄色标记重点
4. 使用批注添加笔记：
   - `<div class="annotation-note">笔记</div>`
   - `<div class="annotation-question">疑问</div>`
   - `<div class="annotation-insight">洞察</div>`
5. 查词：`Ctrl+鼠标悬停` 在单词上
6. 将生词添加到单词库

### 🔄 每日复习

**步骤**：
1. 打开 [[学习中心]] 查看今日任务
2. `Ctrl+P` → "SR: Review flashcards" 开始复习
3. 对每张卡片评分（较难/记得/简单）
4. 复习完成后查看统计数据

### ✍️ 写作练习

**步骤**：
1. `Ctrl+P` → 选择 "写作练习模板"
2. 写下题目要求
3. 在"我的习作"区域写作
4. 使用 English Assistant 的 AI 批改功能
5. 根据反馈修改，记录在"修改版本"
6. 积累好词好句

### 📅 每日学习流程

1. **早晨**：打开 [[学习中心]] → 查看今日计划 → 背新单词
2. **上午**：阅读英文文章 → 标注生词 → 添加到单词库
3. **下午**：听力练习 → 记录听力笔记
4. **晚上**：写作练习/语法学习 → AI批改
5. **睡前**：间隔重复复习 → 回顾今日学习

## 常见问题

### Q: 如何设置学习中心为首页？
A: 设置 → 核心/社区插件 → Homepage 插件（如已安装），或使用 Workspaces 功能保存学习中心为默认工作区。

### Q: 单词卡片的掌握度如何更新？
A: 手动更新笔记的 `mastery` 属性（1-5分），或通过间隔重复复习自动关联。

### Q: 如何添加新的RSS源？
A: 点击左侧RSS图标 → Add Feed → 输入RSS URL → 选择保存文件夹。

### Q: 划词翻译不工作？
A: 检查 language-learner 插件是否启用，确认 `Ctrl+鼠标悬停` 操作正确。
