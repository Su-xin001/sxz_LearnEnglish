## 1. obsidian-spaced-repetition（间隔重复）

### 功能说明
基于SM-2算法的间隔重复记忆系统，支持闪卡复习和笔记复习。

### 关键配置

| 配置项 | 当前值 | 说明 |
|--------|--------|------|
| flashcardTags | `#flashcards` | 识别闪卡的标签 |
| convertHighlightsToClozes | `true` | 高亮文字转为填空题 |
| convertBoldTextToClozes | `true` | 加粗文字转为填空题 |
| singleLineCardSeparator | `::` | 单行卡片分隔符 |
| burySiblingCards | `true` | 隐藏同源卡片 |
| autoNextNote | `true` | 自动切换到下一条笔记 |
| maximumInterval | `365` | 最大复习间隔（天） |
| flashcardEasyText | `简单` | Easy按钮中文标签 |
| flashcardGoodText | `记得` | Good按钮中文标签 |
| flashcardHardText | `较难` | Hard按钮中文标签 |

### 使用方法

1. **创建闪卡**：在笔记中添加 `#flashcards` 标签，使用 `::` 分隔正反面
2. **填空题**：使用 `==高亮==` 或 `**加粗**` 创建填空
3. **开始复习**：`Ctrl+P` → "SR: Review flashcards"
4. **复习评分**：较难 / 记得 / 简单，影响下次复习间隔

### 闪卡格式示例

```
#flashcards

单词 :: 释义
What does "elaborate" mean? :: 精心制作的；详细阐述
She wore an ==elaborate== dress. → 填空题
```

## 2. obsidian-language-learner（语言学习）

### 功能说明
划词翻译、词典查询、单词数据库管理。

### 关键配置

| 配置项 | 当前值 | 说明 |
|--------|--------|------|
| native | `zh` | 母语：中文 |
| foreign | `en` | 外语：英语 |
| popup_search | `true` | 启用弹窗查词 |
| auto_pron | `true` | 自动发音 |
| function_key | `ctrlKey` | 查词触发键：Ctrl |
| dict_height | `300px` | 词典弹窗高度 |
| font_size | `16px` | 字体大小 |
| font_family | Times New Roman | 阅读字体 |
| line_height | `2em` | 行高 |

### 词典优先级

1. **有道词典** — 中文释义最准确
2. **剑桥词典** — 英文释义权威
3. **句酷** — 丰富例句
4. **沪江词典** — 补充释义
5. **DeepL** — 机器翻译

### 使用方法

1. **划词查询**：按住 `Ctrl` + 鼠标悬停在单词上
2. **添加到生词本**：查词后点击保存按钮
3. **批量导入**：将CSV放入 `08-资源/导入` 文件夹

## 3. obsidian-english-assistant（英语助手）

### 功能说明
AI驱动的英语学习助手，支持写作批改、单词查询、对话练习。

### 关键配置

| 配置项 | 当前值 | 说明 |
|--------|--------|------|
| queryStrategy | `local-first` | 优先本地词典 |
| enableLocalDictionary | `true` | 启用本地词典 |
| cacheAIResults | `true` | 缓存AI结果 |
| ttsProvider | `compatible` | TTS提供商 |
| ttsSpeed | `0.9` | 朗读速度 |
| enableProgressTracking | `true` | 启用进度追踪 |
| chatEnableCorrection | `true` | 启用对话纠错 |

### 使用方法

1. **写作批改**：选中英文文本 → 右键 → English Assistant 批改
2. **单词查询**：选中单词 → 查询详细释义
3. **对话练习**：打开对话面板进行英语对话
4. **TTS朗读**：选中文本 → 朗读

### 需要配置

> [!warning] 需要API Key
> AI功能需要配置OpenAI兼容的API Key：
> - 进入插件设置 → 填入 API Key 和 Base URL
> - 推荐使用兼容OpenAI格式的API服务

## 4. hi-words（单词高亮）

### 功能说明
在阅读材料中自动高亮已学单词，悬停显示释义。

### 关键配置

| 配置项 | 当前值 | 说明 |
|--------|--------|------|
| vocabularyBooks | `01-单词库` | 词汇本路径 |
| showDefinitionOnHover | `true` | 悬停显示释义 |
| enableAutoHighlight | `true` | 自动高亮 |
| highlightStyle | `underline` | 高亮样式：下划线 |
| enableMasteredFeature | `true` | 启用掌握标记 |
| highlightPaths | `02-阅读材料` | 高亮作用范围 |
| cardWidth | `280` | 卡片宽度 |
| cardHeight | `140` | 卡片高度 |

### 使用方法

1. **查看高亮**：在阅读材料中，已学单词会自动添加下划线
2. **悬停查词**：鼠标悬停在高亮单词上查看释义
3. **标记掌握**：右键高亮单词 → 标记为已掌握

## 5. dataview（数据查询）

### 功能说明
强大的数据查询引擎，用于构建仪表盘和统计页面。

### 使用方法

在笔记中使用 `dataview` 代码块编写查询：

```dataview
TABLE word, phonetic_us, difficulty
FROM "01-单词库"
WHERE word AND difficulty = "CET4"
SORT word ASC
```

### 常用查询类型

| 类型 | 语法 | 用途 |
|------|------|------|
| TABLE | `TABLE columns FROM folder` | 表格展示 |
| LIST | `LIST FROM folder` | 列表展示 |
| TASK | `TASK FROM folder` | 任务列表 |
| CALENDAR | `CALENDAR date FROM folder` | 日历视图 |

## 6. templater-obsidian（模板引擎）

### 功能说明
高级模板引擎，支持变量、日期格式、自动化操作。

### 模板位置
所有模板存放在 `07-模板` 文件夹中。

### 使用方法

1. `Ctrl+P` → "Templater: Create note from template"
2. 选择对应模板
3. 自动创建包含模板内容的笔记

### 模板变量

| 变量 | 说明 | 示例输出 |
|------|------|----------|
| `{{title}}` | 笔记标题 | elaborate |
| `{{date}}` | 当前日期 | 2026-04-16 |
| `{{time}}` | 当前时间 | 14:30 |
| `{{date:YYYY-MM-DD}}` | 格式化日期 | 2026-04-16 |

## 插件兼容性说明

> [!info] 已知兼容性
> - **language-learner + hi-words**：两者都有划词功能，建议使用 Ctrl+悬停（language-learner）和普通悬停（hi-words）区分
> - **spaced-repetition + dataview**：完全兼容，dataview 可查询 spaced-repetition 的复习数据
> - **english-assistant + language-learner**：互补使用，前者侧重AI功能，后者侧重词典功能
