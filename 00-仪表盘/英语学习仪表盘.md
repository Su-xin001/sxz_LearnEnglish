## 📊 学习统计

### 本周学习概览

```dataview
TABLE study_time AS "⏱学习时长", new_words AS "📝新词数", reviewed_words AS "🔄复习数", mastery_rate AS "📈掌握率"
FROM "05-每日记录"
WHERE date >= date(today) - dur(7 days)
SORT date DESC
```

### 单词掌握情况

```dataview
TABLE length(rows) AS "数量"
FROM "02-单词库"
FLATTEN mastery AS 掌握程度
GROUP BY 掌握程度
SORT 掌握程度 ASC
```

### 近期阅读

```dataview
TABLE difficulty AS "难度", word_count AS "字数", status AS "状态"
FROM "01-阅读材料"
WHERE status
SORT date DESC
LIMIT 10
```

## 📖 待复习单词

```dataview
TABLE phonetic AS "音标", pos AS "词性", mastery AS "掌握度", last_review AS "上次复习"
FROM "02-单词库"
WHERE mastery != "已掌握" AND mastery != ""
SORT last_review ASC
LIMIT 15
```
