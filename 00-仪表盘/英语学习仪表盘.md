## 📊 学习统计

### 单词统计

```dataview
TABLE length(rows) as 数量
FROM "01-单词库"
WHERE 单词
FLATTEN 记忆阶段 as stage
GROUP BY stage
SORT stage ASC
```

### 今日待复习

```dataview
TABLE 下次复习, 难度, 词性
FROM "01-单词库"
WHERE 下次复习 AND 下次复习 <= date(today)
SORT 下次复习 ASC
LIMIT 10
```

### 最近7天新增

```dataview
TABLE 添加日期, 难度, 记忆阶段
FROM "01-单词库"
WHERE 添加日期 AND 添加日期 >= date(today) - dur(7 days)
SORT 添加日期 DESC
```
