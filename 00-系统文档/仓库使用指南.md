# 📚 英语学习仓库使用指南

## 🎯 仓库概述

本仓库是一个功能完善的 Obsidian 英语学习系统，专为系统化支持日常英语学习活动而设计，重点强化阅读能力提升和词汇积累两大核心目标。

### 核心特性

- ✅ **完整的阅读辅助系统** - 支持多种格式文章导入、划词翻译、重点标记
- ✅ **智能词汇管理系统** - 多维度分类、自动高亮、掌握追踪
- ✅ **科学的记忆系统** - 基于 SM-2 间隔重复算法
- ✅ **全面的学习统计** - 进度跟踪、数据分析、可视化报告
- ✅ **便捷的操作流程** - 常用功能 3 步内可达

## 🚀 快速入门

### 第一步：创建今日学习笔记

1. 打开 `03-学习笔记/01-每日笔记/`
2. 按 `Alt+E` 插入模板
3. 选择"每日学习笔记模板"
4. 填写今日学习目标和计划

### 第二步：阅读英文文章

1. 打开 `01-阅读材料/01-每日阅读/`
2. 创建新文件，使用"阅读文章模板"
3. 粘贴或输入英文文章内容
4. 使用 HiWords 自动高亮生词
5. 划词查看释义，记录重点词汇

### 第三步：整理单词

1. 在阅读中遇到生词时，选中单词
2. 使用 Language Learner 插件收藏单词
3. 或手动创建单词笔记到 `02-单词库/`
4. 使用"单词卡片模板"标准化记录

### 第四步：复习巩固

1. 点击左侧边栏的闪卡图标
2. 或按 `Ctrl+Alt+S` 开始复习
3. 根据掌握程度选择"简单/记得/较难"
4. 系统自动安排下次复习时间

## 📖 核心功能详解

### 1️⃣ 阅读文章功能

#### 文章导入方式

**方式一：直接粘贴**
1. 复制英文文章内容
2. 在 Obsidian 中新建文件
3. 粘贴内容到正文

**方式二：PDF 导入**
1. 将 PDF 文件放入 `07-附件资源/PDF/`
2. 使用 PDF 阅读器打开
3. 配合 OCR 插件提取文字

**方式三：RSS 订阅**
1. 使用 RSS Dashboard 插件
2. 订阅英文资讯源
3. 直接阅读并收藏文章

#### 阅读辅助功能

| 功能 | 操作方式 | 说明 |
|------|----------|------|
| **自动高亮** | 自动 | HiWords 自动高亮单词库中的词汇 |
| **悬停查词** | 鼠标悬停 | 鼠标悬停在单词上显示释义 |
| **划词翻译** | 选中+快捷键 | 选中单词后使用 Language Learner 翻译 |
| **重点标记** | `==文本==` | 使用高亮语法标记重点内容 |
| **添加笔记** | `[[链接]]` | 使用双向链接关联相关笔记 |

#### 多色标记系统

```markdown
==黄色== - 重点词汇
==蓝色== - 重要句型  
==绿色== - 精彩表达
==红色== - 难点理解
```

### 2️⃣ 单词管理功能

#### 单词卡片结构

每个单词笔记包含以下信息：

```yaml
---
word: "example"
phonetic: "/ɪɡˈzæmpl/"
part_of_speech: "n./v."
difficulty: "中级"
topic: "学术"
status: "学习中"
date_added: 2025-01-15
source: "科技文章"
---
```

**内容结构**：
1. **基本信息** - 单词、音标、词性
2. **释义** - 中英文释义
3. **例句** - 3个典型例句
4. **记忆方法** - 词根词缀、联想记忆
5. **常见搭配** - 常用搭配短语
6. **闪卡练习** - 间隔重复卡片

#### 多维度分类

**按字母索引**
- 文件夹：`02-单词库/01-按字母索引/`
- 命名：`A-D.md`, `E-H.md`, ...

**按主题分类**
- 文件夹：`02-单词库/02-按主题分类/`
- 标签：`#科技`, `#文化`, `#商业`, `#学术`, `#生活`

**按难度分级**
- 文件夹：`02-单词库/03-按难度分级/`
- 级别：初级 / 中级 / 高级

**词根词缀**
- 文件夹：`02-单词库/04-词根词缀/`
- 分类：常见词根 / 常见前缀 / 常见后缀

#### 单词状态管理

- **新词** - 刚添加，未开始学习
- **学习中** - 正在学习，未掌握
- **已掌握** - 通过复习测试，已掌握

### 3️⃣ 间隔重复记忆系统

#### SM-2 算法简介

SM-2 算法是一种科学的间隔重复算法，根据你的记忆效果动态调整复习间隔：

- **简单** - 延长下次复习间隔
- **记得** - 保持当前复习间隔
- **较难** - 缩短下次复习间隔

#### 复习间隔设置

| 轮次 | 间隔时间 | 说明 |
|------|----------|------|
| 第1次 | 1天后 | 初次学习后复习 |
| 第2次 | 3天后 | 巩固记忆 |
| 第3次 | 7天后 | 加强记忆 |
| 第4次 | 14天后 | 长期记忆 |
| 第5次 | 30天后 | 永久记忆 |

#### 闪卡格式

**单线卡片**
```
单词 (词性)::/音标/ 中文释义
```

**多线卡片**
```
单词 (词性)
?
/音标/
中文释义
例句
```

**双向卡片（可翻转）**
```
单词:::中文释义
```

#### 使用步骤

1. 在单词笔记中添加 `#flashcards` 标签
2. 使用上述格式创建闪卡
3. 按 `Ctrl+Alt+S` 开始复习
4. 根据记忆情况选择难度
5. 系统自动安排下次复习

## 🆘 常见问题

### Q1: 如何快速添加生词到单词库？

**A**: 三种方式：
1. 使用 Language Learner 插件划词收藏
2. 手动创建单词笔记，使用单词卡片模板
3. 在单词总库 Canvas 中直接添加

### Q2: 闪卡复习时如何调整难度？

**A**: 
- **简单** - 完全掌握，延长复习间隔
- **记得** - 基本掌握，保持复习间隔
- **较难** - 不太熟悉，缩短复习间隔

### Q3: 如何查看学习统计？

**A**: 打开 `05-学习数据/01-进度统计/学习数据看板.md`，使用 Dataview 插件自动统计。

### Q4: 如何备份学习数据？

**A**: 
1. Git 插件自动备份到远程仓库
2. 手动复制整个仓库文件夹
3. 使用 Obsidian 同步服务

### Q5: 插件冲突怎么办？

**A**: 
1. 禁用最近安装的插件
2. 逐个启用排查冲突源
3. 查看插件配置说明文档
