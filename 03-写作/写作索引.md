# ✍️ 写作索引

> 写作练习按类型 / 批改状态聚合，`ai_review` 显示 AI 批改结论。

## 全部写作练习

```dataview
TABLE type AS "类型", status AS "状态", ai_review AS "AI 批改"
FROM "03-写作"
WHERE contains(tags, "写作")
SORT date DESC
```

## 待批改

```dataview
TABLE type AS "类型", date AS "日期"
FROM "03-写作"
WHERE contains(tags, "写作") AND status = "待批改"
SORT date DESC
```
