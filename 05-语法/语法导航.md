## 核心语法专题

### 时态体系

| 时态 | 构成 | 用法 |
| ---- | ---- | ---- |
| 一般现在时 | V/V-s | 习惯、事实、真理 |
| 一般过去时 | V-ed | 过去的动作或状态 |
| 一般将来时 | will + V | 将来的计划或预测 |
| 现在进行时 | am/is/are + V-ing | 正在进行的动作 |
| 过去进行时 | was/were + V-ing | 过去某时正在进行的动作 |
| 现在完成时 | have/has + V-ed | 过去发生对现在有影响 |
| 过去完成时 | had + V-ed | 过去的过去 |
| 现在完成进行时 | have/has been + V-ing | 从过去持续到现在 |

### 从句体系

| 类型 | 引导词 | 功能 |
| ---- | ------ | ---- |
| 定语从句 | who/which/that | 修饰名词 |
| 名词性从句 | that/whether/what | 作主语/宾语/表语 |
| 状语从句 | when/because/if | 表示时间/原因/条件 |

### 非谓语动词

| 类型 | 构成 | 功能 |
| ---- | ---- | ---- |
| 不定式 | to + V | 目的、将来 |
| 动名词 | V-ing | 习惯、进行 |
| 分词 | V-ing / V-ed | 修饰、伴随 |
