## 📊 词汇仪表盘

---

### 📈 总体统计

```dataview
TABLE WITHOUT ID
  length(rows) AS 总单词数
FROM "02-Vocabulary/Words"
```

---

### 🎯 掌握度分布

```dataview
TABLE WITHOUT ID
  choice(mastery = 0, "⬜ 未学习",
  choice(mastery = 1, "🟦 初识",
  choice(mastery = 2, "🟩 认识",
  choice(mastery = 3, "🟨 熟悉",
  choice(mastery = 4, "🟧 掌握",
  choice(mastery = 5, "🟥 精通", "❓"))))) AS 等级,
  length(rows) AS 数量
FROM "02-Vocabulary/Words"
GROUP BY mastery
SORT mastery ASC
```

---

### 📚 按难度分布

```dataview
TABLE WITHOUT ID
  difficulty AS 难度等级,
  length(rows) AS 数量
FROM "02-Vocabulary/Words"
GROUP BY difficulty
SORT difficulty ASC
```

---

### 🏷️ 按主题分布

```dataview
TABLE WITHOUT ID
  topic AS 主题,
  length(rows) AS 数量
FROM "02-Vocabulary/Words"
GROUP BY topic
SORT length(rows) DESC
```

---

### 📅 最近学习的单词

```dataview
TABLE WITHOUT ID
  file.link AS 单词,
  meaning-zh AS 释义,
  choice(mastery = 0, "⬜",
  choice(mastery = 1, "🟦",
  choice(mastery = 2, "🟩",
  choice(mastery = 3, "🟨",
  choice(mastery = 4, "🟧",
  choice(mastery = 5, "🟥", "❓"))))) AS 掌握度,
  date AS 学习日期
FROM "02-Vocabulary/Words"
SORT date DESC
LIMIT 15
```

---

### 🔴 待重点复习（掌握度 ≤ 1）

```dataview
TABLE WITHOUT ID
  file.link AS 单词,
  meaning-zh AS 释义,
  mastery AS 掌握度,
  review-count AS 复习次数,
  last-review AS 上次复习
FROM "02-Vocabulary/Words"
WHERE mastery <= 1
SORT mastery ASC, date ASC
LIMIT 20
```

---

### 🟢 已掌握单词（掌握度 ≥ 4）

```dataview
TABLE WITHOUT ID
  file.link AS 单词,
  meaning-zh AS 释义,
  mastery AS 掌握度
FROM "02-Vocabulary/Words"
WHERE mastery >= 4
SORT mastery DESC
```

---

### 🏆 学习进度追踪

```dataview
TABLE WITHOUT ID
  date AS 日期,
  length(rows) AS 当日新增
FROM "02-Vocabulary/Words"
GROUP BY date
SORT date DESC
LIMIT 14
```
