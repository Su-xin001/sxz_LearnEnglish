## 常见英语词根 (Word Roots)

### 核心词根

| 词根 | 含义 | 示例单词 |
|------|------|----------|
| **spect** | 看 | inspect, respect, perspective |
| **dict** | 说 | predict, dictionary, contradict |
| **duct/duc** | 引导 | conduct, produce, introduce |
| **ject** | 投掷 | inject, reject, project |
| **port** | 运送 | transport, import, export |
| **tract** | 拉 | attract, distract, extract |
| **rupt** | 断裂 | interrupt, corrupt, erupt |
| **ven/vent** | 来 | convene, prevent, adventure |
| **scrib/script** | 写 | describe, prescribe, manuscript |
| **cred** | 相信 | credit, incredible, credentials |
| **liber** | 自由/衡量 | liberty, deliberate, liberal |
| **chron** | 时间 | chronic, chronology, synchronize |
| **phon** | 声音 | phonetics, symphony, microphone |
| **graph/gram** | 写/画 | autograph, telegram, paragraph |
| **log** | 说话/学科 | dialogue, biology, logic |
| **min** | 小 | minimum, diminish, minor |
| **maj** | 大 | major, majority, majesty |
| **vac** | 空 | vacant, vacuum, evacuate |
| **flu** | 流 | fluent, influence, fluid |
| **gen** | 产生/种类 | generate, genius, general |

### 常见前缀

| 前缀 | 含义 | 示例 |
|------|------|------|
| **un-** | 不 | unhappy, unable |
| **re-** | 再次 | rebuild, review |
| **pre-** | 之前 | predict, prevent |
| **dis-** | 否定 | disagree, discover |
| **mis-** | 错误 | misunderstand, mistake |
| **over-** | 过度 | overwork, overcome |
| **under-** | 不足 | underestimate, underline |
| **inter-** | 之间 | international, interact |
| **trans-** | 跨越 | transport, translate |
| **sub-** | 下面 | subway, submarine |

### 常见后缀

| 后缀 | 含义 | 示例 |
|------|------|------|
| **-tion/-sion** | 名词化 | action, decision |
| **-ment** | 名词化 | development, movement |
| **-ness** | 名词化 | happiness, darkness |
| **-ful** | 充满 | beautiful, helpful |
| **-less** | 没有 | hopeless, careless |
| **-able/-ible** | 可...的 | readable, possible |
| **-ive** | 倾向于 | active, creative |
| **-ous** | 充满 | dangerous, famous |
| **-ly** | 副词化 | quickly, carefully |
| **-ize** | 动词化 | realize, organize |
