# 阅读材料区

本目录用于存放各类英文阅读材料，按主题分类组织。

## 子目录说明

| 子目录 | 说明 | 难度范围 |
|--------|------|----------|
| 科技 | 科技类文章、技术文档 | 中级-高级 |
| 文学 | 文学作品节选、小说片段 | 中级-高级 |
| 新闻 | 新闻报道、时事文章 | 初级-高级 |
| 学术 | 学术论文、研究报告 | 高级 |
| 日常 | 日常生活类文章、博客 | 初级-中级 |
| 综合 | 其他类型阅读材料 | 初级-高级 |

## 文件命名规则

`YYYYMMDD_难度_文章标题`

示例：`20260414_中级_The Future of AI`
