## 📖 项目概述

sxz_LearnEnglish 是一个基于 [Obsidian](https://obsidian.md) 构建的英语学习知识管理系统，旨在通过结构化的仓库设计、智能化的插件组合和科学的学习方法，打造一个覆盖 **听、说、读、写、译** 全方面的英语学习环境。

本仓库的核心设计理念：

- **结构逻辑性** — 多级目录 + 统一命名规则，符合认知规律和学习习惯
- **操作便捷性** — 常用功能 3 步内可达，18 个自定义快捷键
- **学习高效性** — SM-2 间隔重复算法 + Dataview 数据可视化，减少非学习时间消耗
- **可扩展性** — 模板化设计 + 属性驱动分类，适应长期学习需求变化

## ✨ 主要功能特性

### 📖 阅读辅助

| 功能 | 说明 |
|------|------|
| 多词典悬停查词 | 鼠标悬停单词自动显示释义（有道/剑桥/句酷/沪江/DeepL） |
| 划词翻译 | 选中句子一键翻译为中英双语对照 |
| 重点内容高亮 | 支持不同颜色分类标记，高亮内容自动生成填空卡片 |
| TTS 语音朗读 | 选中文字即可朗读，支持多种语音和语速调节 |
| RSS 文章订阅 | 自动获取 BBC/VOA/Guardian 等英文源文章 |
| YouTube 字幕导入 | 导入视频双语字幕作为学习材料 |

### 📝 单词管理

| 功能 | 说明 |
|------|------|
| 结构化单词条目 | 包含音标、词性、多义项释义、例句、词根词缀分析等完整字段 |
| 三维分类体系 | 按字母索引（A-Z）× 按主题分类（7类）× 按难度分级（6级） |
| 交叉分类筛选 | 同一单词可同时属于多个分类维度，支持 Dataview 快速筛选 |
| 掌握度追踪 | 新学 → 模糊 → 生疏 → 已掌握，四级掌握度动态追踪 |
| 批量导入 | 支持从 CSV/Anki 等外部词库批量导入单词 |

### 🔄 间隔重复复习

| 功能 | 说明 |
|------|------|
| SM-2 算法 | 基于科学记忆曲线的间隔重复，自动安排复习时间 |
| 多种卡片类型 | 单行卡片、多行卡片、填空卡片（高亮自动生成） |
| 按文件夹分牌组 | 阅读卡片、单词卡片、语法卡片自动分组 |
| 复习数据记录 | 每次复习结果记录在笔记中，数据永不丢失 |

### 📊 学习统计

| 功能 | 说明 |
|------|------|
| 学习仪表盘 | 一页总览学习进度、待复习项、近期活动 |
| Dataview 数据查询 | 动态统计词汇量、阅读量、掌握率等关键指标 |
| 每日学习日志 | 自动记录学习时长、新词数、复习数、掌握率 |
| 趋势分析 | 周/月/年学习趋势可视化展示 |

### ✍️ 写作与批改

| 功能 | 说明 |
|------|------|
| AI 写作批改 | 自动检测语法错误，提供修改建议和多种风格改写 |
| 好词好句积累 | 从批改结果中提取高级词汇和表达 |
| 错题本 | 自动记录写作中的常见错误模式 |

## 🚀 安装指南

### 前置要求

- [Obsidian](https://obsidian.md) v1.12 或更高版本
- Git（用于克隆仓库和自动备份）

### 安装步骤

**方式一：克隆仓库（推荐）**

```bash
git clone https://github.com/your-username/sxz_LearnEnglish.git
cd sxz_LearnEnglish
```

**方式二：下载 ZIP**

1. 点击仓库页面的 `Code` → `Download ZIP`
2. 解压到本地目录

**在 Obsidian 中打开**

1. 启动 Obsidian
2. 点击「打开文件夹作为仓库」
3. 选择 `sxz_LearnEnglish` 目录
4. Obsidian 将自动识别 `.obsidian` 配置并加载所有插件

### 插件安装

仓库已包含所有社区插件文件，Obsidian 打开后会自动识别。首次使用需：

1. 进入 **设置 → 社区插件**
2. 点击「信任作者并启用插件」以启用所有插件
3. 重新加载 Obsidian

已配置的 12 个社区插件：

| 插件 | 功能 | 状态 |
|------|------|------|
| obsidian-spaced-repetition | SM-2 间隔重复复习 | ✅ |
| obsidian-language-learner | 多词典查询 + 翻译 | ✅ |
| hi-words | 悬停释义 + 生词高亮 | ✅ |
| ob-english-learner | AI 批改 + TTS + YouTube 导入 | ✅ |
| dataview | 数据查询 + 统计可视化 | ✅ |
| templater-obsidian | 动态模板 + 文件夹模板 | ✅ |
| obsidian-calendar-plugin | 日历视图 + 每日记录 | ✅ |

## 📋 使用方法

### 标准学习闭环

每日学习按以下 6 步形成完整闭环：

```
① 打开每日记录 → ② 阅读文章 → ③ 收集生词 → ④ 整理笔记 → ⑤ 间隔复习 → ⑥ 更新记录
      ↑                                                              │
      └──────────────────────────────────────────────────────────────┘
```

### 快速开始

**1. 创建每日记录**

按 `Alt+N` 或点击日历对应日期，自动生成今日学习日志。

**2. 阅读英文文章**

- 进入 `01-阅读材料` 选择适合难度的文章
- 鼠标悬停单词查看释义
- 选中句子按 `Ctrl+Shift+T` 翻译
- 用 `==高亮==` 标记重点内容

**3. 收集生词**

- 选中单词按 `Ctrl+Shift+A` 添加到词库
- 按 `Alt+2` 使用单词模板创建完整条目
- 填写音标、释义、例句、词根词缀等信息

**4. 间隔复习**

- 按 `Alt+R` 打开复习界面
- 根据记忆情况评分（较难/记得/简单）
- 系统基于 SM-2 算法自动安排下次复习

### 核心快捷键

| 快捷键 | 功能 | 快捷键 | 功能 |
|--------|------|--------|------|
| `Ctrl+Shift+D` | 查词 | `Ctrl+Shift+T` | 翻译 |
| `Ctrl+Shift+A` | 添加到词库 | `Ctrl+Shift+W` | 添加高亮词 |
| `Ctrl+Shift+S` | TTS 朗读 | `Alt+R` | 间隔复习 |
| `Alt+1` | 阅读模板 | `Alt+2` | 单词模板 |
| `Alt+3` | 每日记录模板 | `Alt+N` | 新建每日记录 |
| `Alt+G` | 知识图谱 | `Ctrl+P` | 全局搜索 |

完整快捷键列表请参阅 [快捷键速查表](09-资源与工具/快捷键速查表.md)。

### 文件命名规则

| 内容类型 | 命名格式 | 示例 |
|----------|----------|------|
| 阅读文章 | `YYYYMMDD_文章标题` | `20260412_The Art of Reading` |
| 单词 | `单词本身` | `ephemeral` |
| 每日记录 | `YYYY-MM-DD` | `2026-04-12` |

## 🔌 插件配置说明

### 关键配置

各插件已预配置好最佳参数，主要配置如下：

- **obsidian-spaced-repetition**：闪卡标签 `#flashcards`，按文件夹分牌组，SM-2 算法，最大间隔 365 天
- **obsidian-language-learner**：母语中文/外语英文，功能键 Ctrl，5 个词典按优先级排列
- **hi-words**：词汇本指向 `02-单词库`，高亮范围限定 `01-阅读材料`
- **templater-obsidian**：模板文件夹 `10-模板`，7 个文件夹模板自动匹配
- **obsidian-calendar-plugin**：每日记录文件夹 `05-每日记录`
- **dataview**：启用 JS 查询，2.5 秒自动刷新

### 插件冲突解决方案

| 冲突 | 解决方案 |
|------|----------|
| hi-words 与 language-learner 悬停冲突 | hi-words 负责已学单词高亮，language-learner 负责主动查词 |
| ob-english-learner 与 english-assistant 功能重叠 | 前者侧重视频/音频学习，后者侧重本地词典，按需使用 |

详细配置说明请参阅 [插件评估报告](09-资源与工具/插件评估报告.md) 和 [仓库使用指南](09-资源与工具/仓库使用指南.md)。
