# 🎓 sxz_LearnEnglish — Obsidian 英语学习仓库

> 一个功能完善、高效实用的 Obsidian 英语学习系统，专为大学生设计，以"极其方便日常学习"为核心目标。

## ✨ 功能亮点

### 📚 单词管理系统
- **结构化单词数据库**：每个单词包含音标、词性、多义项释义、例句、记忆方法、派生词、同反义词
- **多维度分类**：按词性 / 主题 / 难度（CET4/CET6/考研/雅思托福）/ 记忆阶段分类
- **多种添加方式**：模板创建、划词添加、CSV批量导入
- **间隔重复复习**：基于 SM-2 算法的科学记忆系统

### 📖 阅读辅助系统
- **划词即时翻译**：Ctrl + 鼠标悬停，多词典源（有道/剑桥/DeepL）
- **多色彩高亮标注**：生词(粉)、好句(橙)、重点(黄)、已掌握(绿)、待复习(蓝)
- **批注系统**：笔记/疑问/洞察三种批注类型
- **生词一键入库**：阅读中遇到的生词直接添加到单词库

### ✍️ 写作练习系统
- **AI 智能批改**：语法纠错、表达优化、多风格改写
- **范文积累**：分类存储优秀范文
- **写作模板**：议论文/说明文/应用文模板

### 🎧 听力资源系统
- **精听三步法**：大意 → 细节 → 查漏补缺
- **媒体增强播放**：时间戳笔记、截图标注
- **TTS 朗读**：选中文本即可朗读

### 📊 数据驱动的学习中心
- **Dataview 仪表盘**：实时统计单词量、阅读量、掌握度
- **学习进度追踪**：按日/周/月查看学习数据
- **间隔重复提醒**：待复习单词自动排列

## 🗂️ 仓库结构

```
sxz_LearnEnglish/
├── 00-仪表盘/       # 学习中心、统计、快捷键指南
├── 01-单词库/       # 单词数据库（按词性/主题/难度/记忆阶段分类）
├── 02-阅读材料/     # 文章、书籍、新闻、真题
├── 03-语法笔记/     # 基础语法、进阶语法、语法专题
├── 04-写作练习/     # 范文积累、写作练习、写作模板
├── 05-听力资源/     # 听力材料、听力笔记
├── 06-学习计划/     # 学习计划与进度追踪
├── 07-模板/         # 标准化模板库（6个模板）
```

## 🚀 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/your-username/sxz_LearnEnglish.git
```

### 2. 用 Obsidian 打开

1. 打开 Obsidian
2. 选择"打开文件夹作为仓库"
3. 选择克隆下来的 `sxz_LearnEnglish` 文件夹

### 3. 安装插件

仓库已包含所有插件文件，但需要手动启用：

1. 进入 设置 → 第三方插件
2. 关闭"安全模式"
3. 点击"重新加载"按钮
4. 逐个启用所需插件

### 4. 启用 CSS 样式

1. 进入 设置 → 外观 → CSS 代码片段
2. 启用以下片段：
   - `英语学习主题`
   - `单词卡片样式`
   - `学习标注样式`
   - `仪表盘样式`

### 5. 开始使用

打开 [[学习中心]] 页面，这是你的学习主页面。

## 📝 日常使用

### 添加新单词
`Ctrl+P` → "Templater: Create note from template" → 选择"单词卡片模板"

### 阅读英文文章
`Ctrl+P` → 选择"阅读笔记模板" → 粘贴原文 → 标注生词

### 复习单词
`Ctrl+P` → "SR: Review flashcards" → 评分复习

### 写作练习
`Ctrl+P` → 选择"写作练习模板" → 写作 → AI批改

## 🎨 自定义样式

仓库包含 4 个 CSS 样式片段，可在 `.obsidian/snippets/` 中找到并自定义：

- **英语学习主题**：紫色主题配色、行距优化、链接样式
- **单词卡片样式**：单词卡片排版、音标、释义、例句样式
- **学习标注样式**：5色高亮、3种批注、单词掌握度标记
- **仪表盘样式**：卡片布局、统计数据、进度条
