# 📋 议论文写作模板

## 结构框架

### 第一段：引言

> In recent years, the issue of **[话题]** has aroused widespread concern. There is a heated debate over whether **[争议点]**. As far as I am concerned, I firmly believe that **[你的观点]**.

### 第二段：论点一

> To begin with, **[论点一]**. A compelling example is that **[例证一]**. This clearly demonstrates that **[小结一]**.

### 第三段：论点二

> Furthermore, **[论点二]**. According to **[数据/研究来源]**, **[数据支撑]**. This evidence strongly supports the view that **[小结二]**.

### 第四段：论点三（可选：让步段）

> Admittedly, **[反方观点]** has some merit. However, **[反驳]**. Therefore, **[重申立场]**.

### 第五段：结论

> In conclusion, taking all the above-mentioned factors into consideration, I strongly advocate that **[重申观点]**. Only by **[建议措施]** can we **[期望结果]**.

## 常用连接词

| 功能 | 表达 |
|------|------|
| 递进 | Furthermore, Moreover, In addition, What's more |
| 转折 | However, Nevertheless, On the contrary, Conversely |
| 因果 | Therefore, Consequently, As a result, Hence |
| 举例 | For instance, For example, Such as, To illustrate |
| 总结 | In conclusion, To sum up, All in all, In summary |
| 对比 | On the one hand...On the other hand, While, Whereas |

## 高分句型

1. **倒装句**: Not only does...but also...
2. **强调句**: It is...that...
3. **虚拟语气**: Were it not for..., ...would...
4. **被动语态**: It is widely acknowledged that...
5. **定语从句**: ..., which plays a crucial role in...
