# 📋 说明文写作模板

## 结构框架

### 第一段：引入主题

> **[主题]** is a topic of great significance in today's world. This essay aims to provide a comprehensive overview of **[说明对象]**, covering its **[说明方面1]**, **[说明方面2]**, and **[说明方面3]**.

### 第二段：说明方面一

> First and foremost, **[方面一的具体说明]**. To be more specific, **[详细解释]**. For instance, **[举例说明]**.

### 第三段：说明方面二

> In addition, **[方面二的具体说明]**. It is worth noting that **[重要细节]**. According to **[权威来源]**, **[数据/事实]**.

### 第四段：说明方面三

> Last but not least, **[方面三的具体说明]**. A case in point is **[典型案例]**, which illustrates **[说明要点]**.

### 第五段：总结

> To summarize, **[总结要点]**. Understanding **[主题]** is essential because **[重要性]**. It is hoped that this explanation provides a clear picture of **[说明对象]**.

## 说明方法

| 方法 | 说明 | 示例句型 |
|------|------|----------|
| 定义说明 | 解释概念含义 | ...refers to... / ...is defined as... |
| 分类说明 | 按类别组织 | ...can be classified into...categories |
| 举例说明 | 用实例佐证 | A good example of this is... |
| 比较说明 | 对比异同 | Compared with..., ...differs in... |
| 数据说明 | 用数据支撑 | Statistics show that... |
| 因果说明 | 分析因果关系 | As a result of..., ... |

## 常用表达

| 功能 | 表达 |
|------|------|
| 定义 | is defined as, refers to, means |
| 分类 | can be divided into, falls into, consists of |
| 举例 | for example, for instance, such as |
| 比较 | similarly, in contrast, whereas |
| 因果 | therefore, as a result, leads to |
| 总结 | in summary, to conclude, overall |
