# 📊 单词掌握度报告

---

## 掌握程度总览

```dataview
TABLE length(rows) AS 数量, 
  round(length(rows) / length(filter(rows, (r) => r.类型 = "单词卡片")) * 100, 1) + "%" AS 占比
FROM "单词库"
WHERE 类型 = "单词卡片"
GROUP BY 掌握程度
```

## 陌生单词列表

```dataview
TABLE 拼写, 国际音标, 词性分类, 添加日期
FROM "单词库"
WHERE 类型 = "单词卡片" AND 掌握程度 = "陌生"
SORT 添加日期 DESC
```

## 熟悉单词列表

```dataview
TABLE 拼写, 国际音标, 词性分类, 添加日期
```

## 本周新增单词

```dataview
TABLE 拼写, 国际音标, 词性分类, 掌握程度
FROM "单词库"
WHERE 类型 = "单词卡片" AND 添加日期 >= date(today) - dur(7 days)
SORT 添加日期 DESC
```

## 按难度等级统计

```dataview
TABLE 
  length(rows) AS 总数,
  length(filter(rows, (r) => r.掌握程度 = "陌生")) AS 陌生,
  length(filter(rows, (r) => r.掌握程度 = "熟悉")) AS 熟悉,
  length(filter(rows, (r) => r.掌握程度 = "掌握")) AS 掌握
FROM "单词库"
WHERE 类型 = "单词卡片"
GROUP BY 难度等级
```
