# 📊 学习数据仪表盘

---

## 📚 阅读材料统计

### 最近阅读的文章

```dataview
TABLE 来源, 难度等级, 词汇量, 阅读日期
FROM "阅读材料"
WHERE 类型 = "阅读材料"
SORT 阅读日期 DESC
LIMIT 10
```

### 按难度分布

```dataview
TABLE length(rows) AS 文章数量
FROM "阅读材料"
WHERE 类型 = "阅读材料"
GROUP BY 难度等级
```

### 按主题分布

```dataview
TABLE length(rows) AS 文章数量
FROM "阅读材料"
WHERE 类型 = "阅读材料"
FLATTEN 标签 AS 标签名
GROUP BY 标签名
```

## 📓 学习笔记统计

### 最近学习笔记

```dataview
TABLE 学习日期, 学习时长, 核心收获
FROM "学习笔记"
WHERE 类型 = "学习笔记"
SORT 学习日期 DESC
LIMIT 10
```

### 每日学习时长

```dataview
TABLE 学习日期, 学习时长
FROM "学习笔记"
WHERE 类型 = "学习笔记"
SORT 学习日期 DESC
LIMIT 30
```

### 学习总时长

```dataview
TABLE length(rows) AS 笔记数, default(sum(rows.学习时长), 0) AS 总时长分钟
FROM "学习笔记"
WHERE 类型 = "学习笔记"
```

## 📈 综合概览

```dataview
TABLE 
  length(filter(rows, (r) => r.类型 = "阅读材料")) AS 阅读材料数,
  length(filter(rows, (r) => r.类型 = "单词卡片")) AS 单词数,
  length(filter(rows, (r) => r.类型 = "学习笔记")) AS 笔记数,
  length(filter(rows, (r) => r.类型 = "复习计划")) AS 复习计划数
FROM "阅读材料" OR "单词库" OR "学习笔记" OR "复习计划"
WHERE 类型
```

## 🏷️ 标签云

```dataview
TABLE length(rows) AS 使用次数
FROM "阅读材料" OR "单词库" OR "学习笔记"
FLATTEN 标签 AS 标签名
WHERE 标签
GROUP BY 标签名
SORT length(rows) DESC
LIMIT 20
```
