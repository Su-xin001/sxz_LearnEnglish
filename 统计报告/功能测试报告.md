## 六、Obsidian MCP优化实施文档

### 6.1 优化概述

基于MCP（Modular Component Protocol）规范，对仓库进行了模块化结构优化，核心目标是确保各功能模块的**接口一致性**、**元数据规范化**和**可扩展性**。

### 6.2 具体优化点

| 编号 | 优化点 | 实施前 | 实施后 |
|------|--------|--------|--------|
| MCP-001 | 模块注册 | 无模块注册机制 | 创建模块注册表，记录7个核心模块 |
| MCP-002 | 接口规范 | 元数据字段不统一 | 统一通用字段（类型+标签）和日期格式 |
| MCP-003 | 依赖关系 | 模块间依赖隐式 | 显式声明模块依赖关系图 |
| MCP-004 | 枚举规范 | 掌握程度/难度等级无约束 | 定义标准枚举值集合 |
| MCP-005 | 插件映射 | 插件与模块关系不清 | 明确插件-模块输入输出映射 |
| MCP-006 | CSS变量 | 硬编码颜色值 | 模块化CSS变量系统 |
| MCP-007 | 类型标识 | 部分文件缺少类型字段 | 所有文件包含类型标识 |

### 6.3 实施步骤

1. **创建模块注册表**（`.obsidian/模块注册表.md`）
   - 定义7个核心模块（M01-M07）
   - 声明模块间依赖关系
   - 规范接口字段和枚举值

2. **统一元数据规范**
   - 所有文件必须包含 `类型` 和 `标签` 字段
   - 日期字段统一为 `YYYY-MM-DD` 格式
   - 掌握程度限定为：陌生/熟悉/掌握
   - 难度等级限定为：初级/中级/中高级/高级 或 初中/高中/四六级/雅思托福

3. **CSS变量模块化**
   - 提取所有硬编码值为CSS变量
   - 新增 `--sr-hard-color`, `--sr-good-color`, `--sr-easy-color`
   - 新增 `--table-header-bg`, `--table-row-hover`, `--table-border`
   - 新增 `--link-color`, `--tag-bg`, `--tag-color`

4. **插件接口映射**
   - 明确每个插件的输入模块和输出模块
   - 定义插件间的数据流向
