# 📊 阅读进度报告

---

## 阅读总量

```dataview
TABLE length(rows) AS 已读文章数
FROM "阅读材料"
WHERE 类型 = "阅读材料"
```

## 按难度阅读统计

```dataview
TABLE length(rows) AS 文章数
FROM "阅读材料"
WHERE 类型 = "阅读材料"
GROUP BY 难度等级
```

## 本周阅读

```dataview
TABLE 来源, 难度等级, 词汇量, 核心主题
FROM "阅读材料"
WHERE 类型 = "阅读材料" AND 阅读日期 >= date(today) - dur(7 days)
SORT 阅读日期 DESC
```

## 本月阅读

```dataview
TABLE 来源, 难度等级, 词汇量, 核心主题
FROM "阅读材料"
WHERE 类型 = "阅读材料" AND 阅读日期 >= date(today) - dur(30 days)
SORT 阅读日期 DESC
```

## 词汇量累计

```dataview
TABLE sum(rows.词汇量) AS 累计接触词汇量
FROM "阅读材料"
WHERE 类型 = "阅读材料" AND 词汇量
```

## 阅读来源分布

```dataview
TABLE length(rows) AS 文章数
FROM "阅读材料"
WHERE 类型 = "阅读材料"
GROUP BY 来源
```
