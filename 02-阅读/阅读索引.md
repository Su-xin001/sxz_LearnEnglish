# 📖 阅读索引

> 阅读笔记按状态聚合（待读 / 精读中 / 已完成）。

## 全部阅读笔记

```dataview
TABLE source AS "来源", status AS "状态", date AS "日期"
FROM "02-阅读"
WHERE contains(tags, "阅读")
SORT date DESC
```

## 精读中

```dataview
TABLE source AS "来源"
FROM "02-阅读"
WHERE contains(tags, "阅读") AND status = "精读中"
SORT date DESC
```
