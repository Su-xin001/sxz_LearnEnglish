# 📝 单词库导航

## 统计概览

```dataview
TABLE length(rows) AS "数量"
FROM "02-单词库"
FLATTEN mastery AS 掌握程度
GROUP BY 掌握程度
SORT 掌握程度 ASC
```

## 按主题分类

```dataview
TABLE length(rows) AS "单词数"
FROM "02-单词库/02-按主题分类"
FLATTEN file.folder AS 分类
GROUP BY 分类
SORT 分类 ASC
```

## 按难度分级

```dataview
TABLE length(rows) AS "单词数"
FROM "02-单词库/03-按难度分级"
FLATTEN file.folder AS 级别
GROUP BY 级别
SORT 级别 ASC
```

## 最近添加

```dataview
TABLE phonetic AS "音标", pos AS "词性", mastery AS "掌握度"
FROM "02-单词库"
SORT file.ctime DESC
LIMIT 20
```

## 待复习单词

```dataview
TABLE phonetic AS "音标", pos AS "词性", last_review AS "上次复习"
FROM "02-单词库"
WHERE mastery = "生疏" OR mastery = "模糊"
SORT last_review ASC
LIMIT 20
```
