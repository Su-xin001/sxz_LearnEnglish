# 📚 词汇索引

> 全部单词按难度/词性/记忆阶段动态聚合。新建单词卡请保存到 `01-词汇/<难度>/` 并打 `#flashcards/<难度>` 标签。

## 全部单词

```dataview
TABLE pos AS "词性", difficulty AS "难度", stage AS "阶段"
FROM "01-词汇"
WHERE contains(tags, "单词")
SORT difficulty ASC, word ASC
```

## 按难度筛选

- CET4：`WHERE contains(tags, "flashcards/CET4")`
- CET6：`WHERE contains(tags, "flashcards/CET6")`
- 考研：`WHERE contains(tags, "flashcards/考研")`
- 雅思托福：`WHERE contains(tags, "flashcards/雅思托福")`

```dataview
TABLE word AS "单词", pos AS "词性", stage AS "阶段"
FROM "01-词汇"
WHERE contains(tags, "flashcards/考研") OR contains(tags, "flashcards/雅思托福")
SORT word ASC
```

## 待复习/学习中（stage = learning）

```dataview
TABLE word AS "单词", difficulty AS "难度"
FROM "01-词汇"
WHERE contains(tags, "单词") AND stage = "learning"
SORT difficulty ASC
```
