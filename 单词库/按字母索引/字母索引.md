# 📖 单词字母索引

> 按字母顺序快速查找单词卡片

---

## A

```dataview
LIST
FROM "单词库"
WHERE 类型 = "单词卡片" AND startswith(拼写, "a")
SORT 拼写 ASC
```

## F - Z

LIST
FROM "单词库"
