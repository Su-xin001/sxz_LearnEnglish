# 单词数据库

> [!info] 使用说明
> 本文件为单词总数据库，所有单词通过内部链接关联到对应的单词条目。
> 使用 Dataview 查询可按不同维度筛选和展示单词。

## 全部单词

```dataview
TABLE 
  词性, 难度等级, 掌握程度, 首次添加日期
FROM "单词库"
WHERE 单词
SORT 单词 ASC
```

## 按掌握程度筛选

### 未掌握

```dataview
TABLE 词性, 难度等级, 复习次数, 下次复习
FROM "单词库"
```
