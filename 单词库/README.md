# 单词库

本目录用于存放结构化单词卡片数据，支持多维度分类管理。

## 文件命名规则

`单词_词性_主题`

示例：`elaborate_动词_学术词汇`

## 单词卡片模板字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 拼写 | 单词正确拼写 | elaborate |
| 国际音标 | IPA音标 | /ɪˈlæbərət/ |
| 词性分类 | 名词/动词/形容词等 | 动词/形容词 |
| 多义项释义 | 各义项中英对照 | v. 详细阐述; adj. 精心制作的 |
| 典型例句 | 含中文翻译 | Please elaborate on your idea. 请详细阐述你的想法。 |
| 记忆方法 | 词根词缀/联想 | e-(出)+labor(劳动)+ate → 精心劳作 → 精心制作 |
| 掌握程度 | 陌生/熟悉/掌握 | 陌生 |
| 添加日期 | ISO格式日期 | 2026-04-14 |
