## Custom Hotkey Setup Guide

1. Open Obsidian Settings (Ctrl+,)
2. Navigate to "Hotkeys"
3. Search for the desired command
4. Click the hotkey field and press your desired key combination
5. Save and test

## Recommended Workflow Hotkeys

### Reading Workflow
1. Ctrl+Alt+R → Open reading folder
2. Select article → Read with HiWords highlighting
3. Ctrl+Shift+W → Add unfamiliar words to vocabulary
4. Ctrl+Alt+W → Review added words

### Vocabulary Workflow
1. Ctrl+Alt+N → New vocabulary note
2. Fill template with word details
3. Ctrl+Alt+F → Create flashcard from word
4. Ctrl+Shift+R → Review flashcard

### Daily Review Workflow
1. Ctrl+Alt+D → Open daily note
2. Ctrl+Shift+R → Start spaced repetition
3. Review all due cards
4. Update statistics
