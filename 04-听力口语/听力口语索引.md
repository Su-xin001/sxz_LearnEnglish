# 🎧 听力口语索引

> 听力精听笔记按状态聚合（待精听 / 精听中 / 已完成）。

## 全部听力笔记

```dataview
TABLE source AS "来源", status AS "状态", date AS "日期"
FROM "04-听力口语"
WHERE contains(tags, "听力")
SORT date DESC
```

## 精听中

```dataview
TABLE source AS "来源"
FROM "04-听力口语"
WHERE contains(tags, "听力") AND status = "精听中"
SORT date DESC
```
