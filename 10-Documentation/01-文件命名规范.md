# 📋 文件命名规范

## 一、命名原则
- **统一格式**: 所有文件采用统一的命名格式，便于排序和检索
- **语义清晰**: 文件名应清晰表达内容主题
- **日期前缀**: 时间相关文件使用日期前缀，便于时间排序
- **避免特殊字符**: 不使用 `\ / : * ? " < > |` 等特殊字符

## 二、具体命名规则

### 1. 阅读文章
**格式**: `YYYYMMDD_文章标题_难度级别.md`

**示例**:
- `20260411_ClimateChange_Impacts_Intermediate.md`
- `20260412_TechnologyInnovation_Advanced.md`
- `20260413_DailyConversation_Beginner.md`

**说明**:
- `YYYYMMDD`: 阅读日期
- `文章标题`: 英文标题，单词首字母大写，用下划线连接
- `难度级别`: Beginner/Intermediate/Advanced

### 2. 单词卡片
**格式**: `单词_词性_主题_难度.md`

**示例**:
- `abandon_v_Academic_CET4.md`
- `achievement_n_Business_CET6.md`
- `collaboration_n_Technology_IELTS.md`

**说明**:
- `单词`: 小写，连字符用下划线
- `词性`: n/v/adj/adv/prep 等
- `主题`: Academic/Business/Daily/Technology 等
- `难度`: CET4/CET6/IELTS/TOEFL 等

### 3. 学习笔记
#### 3.1 每日笔记
**格式**: `YYYY-MM-DD_学习日志.md`

**示例**:
- `2026-04-11_学习日志.md`
- `2026-04-12_学习日志.md`

#### 3.2 周复习
**格式**: `YYYY-Www_周复习.md`

**示例**:
- `2026-W15_周复习.md` (第 15 周)
- `2026-W16_周复习.md`

#### 3.3 月总结
**格式**: `YYYYMM_月度总结.md`

**示例**:
- `202604_月度总结.md`
- `202605_月度总结.md`

### 4. 听力材料
**格式**: `YYYYMMDD_材料类型_主题_时长.md`

**示例**:
- `20260411_Podcast_Technology_15min.md`
- `20260412_NEWS_Business_5min.md`
- `20260413_TEDTalk_Education_18min.md`

### 5. 写作练习
**格式**: `YYYYMMDD_文体_主题_字数.md`

**示例**:
- `20260411_Essay_ClimateChange_300words.md`
- `20260412_Email_JobApplication_150words.md`
- `20260413_Report_MarketAnalysis_500words.md`

### 6. 口语录音
**格式**: `YYYYMMDD_话题_时长.md`

**示例**:
- `20260411_SelfIntroduction_2min.mp3`
- `20260412_Debate_Technology_5min.mp3`

### 7. 复习卡片
**格式**: `Review_单词组_日期.md`

**示例**:
- `Review_CET4_Unit1_20260411.md`
- `Review_IELTS_Words_20260412.md`

## 三、标签使用规范

### 1. 难度标签
- `#beginner` - 初级
- `#intermediate` - 中级
- `#advanced` - 高级

### 2. 主题标签
- `#academic` - 学术
- `#business` - 商务
- `#daily-life` - 日常生活
- `#technology` - 科技
- `#culture` - 文化
- `#news` - 新闻

### 3. 类型标签
- `#vocabulary` - 词汇
- `#grammar` - 语法
- `#reading` - 阅读
- `#listening` - 听力
- `#speaking` - 口语
- `#writing` - 写作

### 4. 状态标签
- `#to-review` - 待复习
- `#in-progress` - 进行中
- `#completed` - 已完成
- `#mastered` - 已掌握

## 四、元数据规范

### 1. 通用元数据字段
```yaml
---
created: YYYY-MM-DD
modified: YYYY-MM-DD
tags: [tag1, tag2]
status: in-progress|completed
source: 来源链接或书名
author: 作者
---
```

### 2. 单词卡片元数据
```yaml
---
word: 单词
phonetic: 音标
level: CET-4|CET-6|IELTS|TOEFL
topic: 主题
difficulty: 1-5
last-reviewed: YYYY-MM-DD
next-review: YYYY-MM-DD
---
```

### 3. 阅读文章元数据
```yaml
---
difficulty: Beginner|Intermediate|Advanced
reading-time: 分钟数
word-count: 单词数
new-words: [单词 1, 单词 2]
---
```

## 五、文件夹命名

### 1. 主文件夹 (使用数字前缀排序)
- `00-Inbox` - 临时收集箱
- `01-Reading` - 阅读材料
- `02-Vocabulary` - 词汇库
- `03-Notes` - 学习笔记
- `04-Writing` - 写作练习
- `05-Listening` - 听力材料
- `06-Speaking` - 口语练习
- `07-Review-System` - 复习系统
- `08-Resources` - 资源库
- `09-Templates` - 模板库
- `10-Documentation` - 文档说明

### 2. 子文件夹命名
- 使用英文，首字母大写
- 多个单词用连字符连接
- 示例：`By-Topic`, `By-Level`, `Daily-Notes`

## 六、内部链接规范

### 1. 单词链接
```markdown
[[abandon_v_Academic_CET4|abandon]]
[[单词名_词性_主题_难度]]
```

### 2. 文章链接
```markdown
[[20260411_ClimateChange_Intermediate|气候变化文章]]
[[日期_标题_难度|显示文本]]
```

### 3. 笔记链接
```markdown
[[2026-04-11_学习日志]]
[[2026-W15_周复习]]
```

### 4. 标签链接
```markdown
#vocabulary #to-review #CET-4
```

## 七、最佳实践

1. **及时整理**: 每天学习结束后整理文件，确保命名规范
2. **定期清理**: 每周检查 Inbox 文件夹，将内容归类
3. **保持一致**: 严格按照规范命名，不要随意简化
4. **善用标签**: 配合标签系统，提高检索效率
5. **建立索引**: 为重要内容建立 MOC (Map of Content) 索引页
