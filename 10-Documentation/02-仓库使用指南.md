本仓库是一个功能完善、结构清晰的英语学习系统，基于 Obsidian 笔记软件构建。旨在帮助你：

- ✅ 追踪学习进度和成果
- ✅ 建立完整的英语学习闭环

## 🔌 核心插件说明

### 已安装插件

#### 1. **Obsidian English Assistant** 🇬🇧
**功能**: 英语词典和翻译辅助
- 划词翻译
- 单词查询
- 音标显示
- 例句展示

**使用方式**:
- 选中英文单词 → 右键 → 查询单词
- 或使用快捷键 `Ctrl+Shift+D`

- 点击 "Review" 开始复习

#### 7. **RSS Dashboard** 📰

## 🛠️ 功能模块详解

### 一、阅读文章功能 📖

#### 1. 文章导入
**支持格式**:
- 直接粘贴文本
- 导入 PDF/EPUB
- RSS 自动抓取
- 网页剪藏

**操作步骤**:
1. 选择合适难度级别文件夹
2. 使用模板创建新笔记
3. 粘贴或导入文章内容
4. 填写元数据（来源、难度、时间等）

#### 2. 单词查询
**方法一：划词查询**
1. 选中不认识的单词
2. 右键 → "查询单词"
3. 查看释义和例句

**方法二：悬停预览**
1. 将鼠标悬停在单词上
2. 自动显示释义卡片

#### 3. 笔记标注
**高亮标记**:
- `==重要内容==` - 黄色高亮
- `%%批注内容%%` - 删除线批注

**添加注释**:
```markdown
生词 (注释内容)
```

#### 4. 词汇提取
使用 Dataview 自动提取文章中的生词：

````markdown
```dataview
TABLE word, phonetic, level
FROM "02-Vocabulary"
WHERE contains(source, this.file.name)
```
````

### 二、单词管理功能 📝

#### 1. 创建单词卡片

**手动创建**:
1. 使用模板 `Vocabulary-Card-Template`
2. 填写完整信息
3. 添加标签和分类

**快速添加**:
1. 阅读时选中单词
2. 使用快捷键创建卡片
3. 自动填充基本信息

#### 2. 单词信息结构

```markdown
# abandon

## 基本信息
- **拼写**: abandon
- **音标**: /əˈbændən/
- **词性**: v.

## 释义
- **中文**: 放弃；抛弃
- **英文**: to leave completely and finally
- **例句**: 
  - The baby had been abandoned by its mother.
  - 这个婴儿被母亲抛弃了。

## 记忆方法
- **词根**: ab-(离开) + don-(给予) → 给予出去 → 放弃
- **联想**: 一个 (a) 绑 (ban) 住的人，最终放弃 (don) 了

## 相关词汇
- **同义词**: desert, forsake, quit
- **反义词**: retain, keep
- **派生词**: abandonment (n.)
```

#### 3. 多维度分类

**按字母索引**:
- 文件存储在对应字母文件夹
- 便于快速查找

**按主题分类**:
- 使用标签 `#academic`, `#business` 等
- 创建主题词汇集合

**按难度分级**:
- 元数据中标注难度级别
- 使用不同颜色标签区分

### 三、复习系统功能 🔄

#### 1. 间隔重复算法

基于 SM-2 算法，自动安排复习时间：

```
复习间隔：
- 第 1 次：1 天后
- 第 2 次：3 天后
- 第 3 次：7 天后
- 第 4 次：14 天后
- 第 5 次：30 天后
```

#### 2. 卡片创建格式

```markdown
#flashcards

**Q**: abandon 的意思是什么？

**A**: 
- v. 放弃；抛弃
- n. 放纵

#vocabulary #CET-4
```

#### 3. 复习流程

1. 打开 "Review" 面板
2. 选择要复习的牌组
3. 回答卡片问题
4. 选择掌握程度：
   - Again (忘记) → 1 分钟后
   - Hard (困难) → 2 天后
   - Good (良好) → 正常间隔
   - Easy (简单) → 延长间隔

## ⌨️ 快捷键配置

### 推荐快捷键设置

在 `设置 → 快捷键` 中配置：

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 查询单词 | `Ctrl+Shift+D` | 快速查词 |
| 创建单词卡片 | `Ctrl+Shift+V` | 添加生词 |
| 插入模板 | `Ctrl+Shift+T` | 使用模板 |
| 开始复习 | `Ctrl+Shift+R` | 间隔复习 |
| 今日笔记 | `Ctrl+Shift+N` | 打开日记 |
| 随机笔记 | `Ctrl+Shift+O` | 随机浏览 |
| 切换预览 | `Ctrl+E` | 编辑/预览 |
| 全局搜索 | `Ctrl+Shift+F` | 搜索内容 |

### 自定义热键

1. 打开设置 → 快捷键
2. 搜索功能名称
3. 点击设置快捷键
4. 输入 desired 组合键

## 🚀 最佳实践建议

### 1. 学习流程

```
阅读文章 → 收集生词 → 制作卡片 → 定期复习 → 总结反思
```

### 2. 时间管理

- **晨间** (15min): 复习昨日单词
- **午间** (30min): 阅读新文章
- **晚间** (15min): 整理笔记，制定明日计划

### 3. 复习策略

- 每日复习：新词次日复习
- 每周复习：周末总结本周内容
- 每月复习：月末回顾重点难点

### 4. 内容组织

- 及时整理 Inbox 内容
- 定期清理过时资料
- 建立内容索引 (MOC)
- 保持标签系统简洁

## 🔧 常见问题排查

### 1. 插件不工作

**解决方案**:
1. 检查插件是否启用
2. 重启 Obsidian
3. 重新安装插件
4. 查看控制台错误

### 2. 模板不生效

**解决方案**:
1. 检查模板路径是否正确
2. 确认 Templater 插件已启用
3. 检查模板语法

### 3. Dataview 查询无结果

**解决方案**:
1. 检查元数据格式
2. 确认路径正确
3. 查看语法错误
4. 重建索引

### 4. 同步冲突

**解决方案**:
1. 使用 Git 管理版本
2. 定期备份
3. 避免多设备同时编辑
