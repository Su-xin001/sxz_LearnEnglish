# ⌨️ 推荐快捷键配置

> 为英语学习优化的快捷键设置

---

## 🎯 核心快捷键

### 学习相关
| 功能 | 推荐快捷键 | 说明 |
|------|-----------|------|
| 查询单词 | `Ctrl+Shift+D` | Obsidian English Assistant |
| 创建单词卡片 | `Ctrl+Shift+V` | 快速添加生词 |
| 开始复习 | `Ctrl+Shift+R` | Spaced Repetition 复习 |
| 今日笔记 | `Ctrl+Shift+N` | 创建/打开每日笔记 |
| 插入模板 | `Ctrl+Shift+T` | Templater 模板 |

### 导航相关
| 功能 | 推荐快捷键 | 说明 |
|------|-----------|------|
| 快速打开 | `Ctrl+O` | 搜索并打开笔记 |
| 全局搜索 | `Ctrl+Shift+F` | 跨文件搜索 |
| 当前笔记搜索 | `Ctrl+F` | 文件内搜索 |
| 查找下一个 | `F3` | 下一个匹配项 |
| 查找上一个 | `Shift+F3` | 上一个匹配项 |

### 编辑相关
| 功能 | 推荐快捷键 | 说明 |
|------|-----------|------|
| 加粗 | `Ctrl+B` | **text** |
| 斜体 | `Ctrl+I` | *text* |
| 高亮 | `Ctrl+Shift+H` | ==text== |
| 删除线 | `Ctrl+Shift+X` | ~~text~~ |
| 插入链接 | `Ctrl+K` | [[link]] |
| 插入标签 | `Ctrl+Shift+L` | #tag |

## 🔧 插件快捷键

### Obsidian English Assistant
```
查询单词：Ctrl+Shift+D
发音播放：Ctrl+Shift+P
加入收藏：Ctrl+Shift+A
```

### Spaced Repetition
```
开始复习：Ctrl+Shift+R
创建卡片：Ctrl+Shift+C
查看统计：Ctrl+Shift+S
```

### Templater
```
插入模板：Ctrl+Shift+T
运行脚本：Ctrl+Shift+J
```

### Dataview
```
刷新查询：Ctrl+Shift+D
```

## 📱 移动端快捷键

### 工具栏配置
推荐将以下命令添加到移动端工具栏：

1. **插入链接** - editor:insert-link
2. **插入标签** - editor:insert-tag
3. **加粗** - editor:toggle-bold
4. **高亮** - editor:toggle-highlight
5. **列表** - editor:toggle-bullet-list
6. **待办事项** - editor:toggle-checklist
7. **查询单词** - english-assistant:lookup-word
8. **创建卡片** - spaced-repetition:create-card

## ⚡ 高效操作技巧

### 1. 快速查词流程
```
1. 选中单词 (双击)
2. Ctrl+Shift+D (查询)
3. 查看释义
4. Ctrl+Shift+V (创建卡片)
5. 补充信息
```

### 2. 阅读笔记流程
```
1. Ctrl+Shift+N (创建笔记)
2. 粘贴文章内容
3. Ctrl+Shift+T (使用阅读模板)
4. 高亮重点内容
5. 添加标签和链接
```

### 3. 复习流程
```
1. Ctrl+Shift+R (开始复习)
2. 回答卡片问题
3. 选择掌握程度
4. 继续下一张
```

## 🎨 自定义快捷键

### 设置方法
1. 打开设置 → 快捷键
2. 搜索功能名称
3. 点击设置快捷键
4. 输入 desired 组合键
5. 确认保存

### 推荐自定义
```
- 切换预览/编辑：Ctrl+E
- 大纲视图：Ctrl+Shift+O
- 图谱视图：Ctrl+Shift+G
- 随机笔记：Ctrl+Shift+R
- 星标笔记：Ctrl+Shift+S
```

## 💡 使用建议

### 初学者
建议先掌握以下 5 个核心快捷键：
1. `Ctrl+Shift+N` - 今日笔记
2. `Ctrl+Shift+D` - 查询单词
3. `Ctrl+Shift+V` - 创建卡片
4. `Ctrl+B` - 加粗
5. `Ctrl+F` - 搜索
