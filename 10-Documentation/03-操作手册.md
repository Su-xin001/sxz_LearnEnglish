## 🎯 标准学习流程

### 一、每日学习流程

#### 1️⃣ 晨间复习 (15 分钟)

**步骤**:
1. 打开 Obsidian，点击左侧边栏 "Review" 图标
2. 选择今日待复习的单词卡片
3. 依次回答卡片问题
4. 根据掌握程度选择：Again/Hard/Good/Easy
5. 记录复习结果到每日笔记

**操作示例**:
```markdown
## 📊 晨间复习
- 应复习：20 词
- 已复习：20 词
- 掌握率：85%
- 易错词：[[abandon]], [[ambiguous]], [[analogy]]
```

#### 2️⃣ 阅读训练 (30 分钟)

**步骤**:
1. 选择合适难度的文章
2. 使用模板创建新笔记
3. 粘贴或导入文章内容
4. 通读全文，标记生词
5. 查询生词并制作卡片
6. 分析难句结构
7. 总结文章主旨

**详细操作**:

**Step 1: 创建阅读笔记**
```
快捷键：Ctrl+Shift+T
选择模板：Reading-Article-Template
填写元数据：日期、来源、难度
```

**Step 2: 标记生词**
```markdown
原文标注:
The scientist made a groundbreaking ==breakthrough== in cancer research.
(生词用高亮标记)
```

**Step 3: 查询单词**
```
1. 选中单词 "groundbreaking"
2. 右键 → "查询单词" 或 Ctrl+Shift+D
3. 查看释义和例句
```

**Step 4: 创建单词卡片**
```
1. 选中单词
2. 右键 → "添加到词汇库"
3. 或使用快捷键 Ctrl+Shift+V
4. 自动跳转到词汇卡片
5. 补充完整信息
```

**Step 5: 记录笔记**
```markdown
## 学习笔记
### 背景知识
- 癌症研究的重要性
- 最新进展

### 语言特点
- 科技文献常用表达
- 被动语态使用频繁
```

#### 3️⃣ 词汇积累 (20 分钟)

**步骤**:
1. 整理阅读中收集的生词
2. 完善单词卡片信息
3. 添加标签和分类
4. 制作记忆卡片
5. 设置复习计划

**单词卡片完整填写**:
```markdown
---
word: "groundbreaking"
phonetic: "/ˈɡraʊndˌbreɪkɪŋ/"
level: "IELTS"
topic: "Academic"
---

# groundbreaking

## 基本信息
- **词性**: adj.
- **释义**: 开创性的；突破性的
- **英文**: innovative; pioneering

## 例句
- This is a groundbreaking discovery.
- 这是一个突破性的发现。

## 记忆方法
- **词根**: ground(基础) + breaking(打破)
- **联想**: 打破基础 → 开创性的

## 相关词汇
- **同义词**: innovative, revolutionary
- **反义词**: traditional, conventional
```

#### 4️⃣ 晚间总结 (15 分钟)

**步骤**:
1. 打开今日笔记
2. 填写学习统计
3. 记录收获与反思
4. 制定明日计划
5. 同步备份数据

**每日笔记模板**:
```markdown
# 📅 学习日志 2026 年 04 月 11 日 星期五

## 🎯 今日目标
- [x] 复习 20 个单词 ✅
- [x] 阅读 1 篇文章 ✅
- [x] 学习 10 个新词 ✅

## 📚 学习内容
### 阅读
- 文章：Climate Change Impacts
- 时长：30 分钟
- 生词：15 个

### 词汇
- 新学：10 个
- 复习：20 个
- 掌握率：85%

## 💡 今日收获
1. 学习了气候变化相关词汇
2. 掌握了科技文章阅读技巧
3. 理解了长难句分析方法

## 🔍 问题反思
- 阅读速度偏慢 → 需要增加练习
- 部分单词易混 → 加强对比记忆

## 📝 明日计划
- [ ] 复习今日单词
- [ ] 阅读新文章
- [ ] 练习听力
```

## 🔧 常见操作步骤

### 一、文章阅读相关

#### 1. 导入网络文章

**方法一：直接粘贴**
```
1. 复制网页内容 (Ctrl+C)
2. 在 Obsidian 创建新笔记
3. 粘贴内容 (Ctrl+V)
4. 清理格式，保留纯文本
5. 添加元数据和标签
```

**方法二：使用剪藏插件**
```
1. 安装 Web Clipper 插件
2. 浏览器点击插件图标
3. 选择要保存的内容
4. 选择保存到文件夹
5. 点击保存
```

**方法三：RSS 自动导入**
```
1. 打开 RSS Dashboard 插件
2. 添加订阅源 URL
3. 设置更新频率
4. 选择文章导入
5. 自动创建笔记
```

#### 2. 批量导入文章

```
1. 准备文章文件 (TXT/PDF/EPUB)
2. 放入 00-Inbox 文件夹
3. 使用 Markdown Importer 插件
4. 批量转换为笔记
5. 分类到对应文件夹
```

#### 3. 添加音频朗读

```markdown
![[audio-file.mp3]]

或使用 HTML5:
<audio controls>
  <source src="audio-file.mp3" type="audio/mpeg">
</audio>
```

### 二、词汇管理相关

#### 1. 快速添加单词

**方法一：右键菜单**
```
1. 选中单词
2. 右键 → "Add to Vocabulary"
3. 自动创建卡片
4. 补充信息
```

**方法二：快捷键**
```
1. 选中单词
2. 按 Ctrl+Shift+V
3. 跳转到词汇笔记
4. 编辑完善
```

**方法三：命令面板**
```
1. Ctrl+P 打开命令面板
2. 输入 "Add Word"
3. 输入单词拼写
4. 自动创建卡片
```

#### 2. 批量导入单词

**准备单词列表**:
```csv
word,phonetic,level,topic
abandon,/əˈbændən/,CET-4,Academic
ability,/əˈbɪləti/,CET-4,General
```

**导入步骤**:
```
1. 准备 CSV 文件
2. 使用 Import 插件
3. 映射字段
4. 批量创建卡片
5. 检查导入结果
```

#### 3. 制作单词卡片

**基础卡片格式**:
```markdown
#flashcards

**Q**: abandon 的中文意思？

**A**: v. 放弃；抛弃

#vocabulary #CET-4
```

**完整卡片格式**:
```markdown
#flashcards

**Q**: 请解释 "groundbreaking" 的含义并造句

**A**: 
- **含义**: 开创性的；突破性的
- **词性**: adj.
- **例句**: This is a groundbreaking discovery.

#vocabulary #IELTS #academic
```

## 🐛 问题排查指南

### 一、插件问题

#### 1. 插件无法加载

**症状**: 插件列表中看不到插件

**解决方案**:
```
1. 检查 Obsidian 版本
2. 关闭 "安全模式"
3. 启用第三方插件
4. 重新安装插件
5. 查看控制台错误
```

#### 2. 插件功能异常

**症状**: 插件功能不工作

**解决方案**:
```
1. 检查插件设置
2. 确认权限已授予
3. 重启 Obsidian
4. 更新插件版本
5. 查看插件文档
```

### 二、模板问题

#### 1. 模板无法插入

**症状**: 使用模板命令无反应

**解决方案**:
```
1. 检查模板路径设置
2. 确认 Templater 已启用
3. 检查模板文件存在
4. 验证模板语法
5. 重启 Templater
```

#### 2. 变量不生效

**症状**: {{date}} 等变量显示原文本

**解决方案**:
```
1. 使用正确的变量语法
2. 检查 Templater 设置
3. 确认触发模式
4. 查看变量列表
```

### 三、同步问题

#### 1. Git 冲突

**症状**: 同步时出现冲突

**解决方案**:
```
1. 查看冲突文件
2. 手动解决冲突
3. 选择保留版本
4. 标记解决
5. 重新提交
```

#### 2. 数据丢失

**症状**: 笔记内容消失

**解决方案**:
```
1. 检查版本历史
2. 使用 Git 恢复
3. 查看回收站
4. 从备份恢复
5. 联系技术支持
```

### 四、性能问题

#### 1. 运行缓慢

**症状**: Obsidian 响应慢

**解决方案**:
```
1. 减少插件数量
2. 禁用不常用插件
3. 清理大文件
4. 重建索引
5. 重启应用
```

#### 2. 搜索缓慢

**症状**: 搜索速度慢

**解决方案**:
```
1. 排除大文件夹
2. 减少笔记数量
3. 优化查询语法
4. 重建索引缓存
```

## 🎨 个性化配置建议

### 一、针对不同学习目标

#### 1. 应试导向 (四六级/雅思托福)

**重点配置**:
```
- 词汇库：按考试分类
- 复习频率：每日 50+ 词
- 阅读材料：真题/模拟题
- 听力训练：考试题型
```

**插件推荐**:
```
- Spaced Repetition (必装)
- Hi-Words (词频统计)
- RSS Dashboard (真题订阅)
```

#### 2. 应用导向 (工作/生活)

**重点配置**:
```
- 词汇库：按场景分类
- 阅读材料：新闻/邮件/文档
- 听力训练：播客/视频
- 口语练习：情景对话
```

**插件推荐**:
```
- Media Extended (视频学习)
- Obsidian English Assistant (快速查词)
- Various Complements (自动补全)
```

#### 3. 学术导向 (论文/研究)

**重点配置**:
```
- 词汇库：学术词汇表
- 阅读材料：论文/期刊
- 笔记系统：文献笔记
- 引用管理：参考文献
```

**插件推荐**:
```
- Dataview (文献管理)
- Citations (引用插件)
```

## 📊 学习统计模板

### 每日统计

````markdown
```dataview
TABLE sum(new-words) as "新词", 
       sum(review-words) as "复习", 
       sum(study-time) as "时长 (分钟)"
FROM "03-Notes/Daily-Notes"
WHERE date = date(today)
```
````

### 每周统计

````markdown
```dataview
TABLE sum(new-words) as "新词", 
       sum(review-words) as "复习"
FROM "03-Notes/Daily-Notes"
WHERE date >= date(2026-04-01) 
  AND date < date(2026-04-08)
```
````

### 月度统计

````markdown
```dataview
TABLE sum(new-words) as "新词", 
       sum(review-words) as "复习",
       round(sum(study-time)/60, 1) as "时长 (小时)"
FROM "03-Notes/Daily-Notes"
WHERE date >= date(2026-04-01) 
  AND date < date(2026-05-01)
```
````
