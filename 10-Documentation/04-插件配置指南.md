## 🎯 核心学习插件

### 1. Obsidian English Assistant ⭐⭐⭐⭐⭐

**功能定位**: 英语词典和翻译辅助工具

**核心功能**:
- ✅ 划词翻译
- ✅ 单词详细释义
- ✅ 音标显示
- ✅ 例句展示
- ✅ 发音播放

**配置步骤**:

1. **基础设置**
```
设置 → 社区插件 → Obsidian English Assistant → 设置
```

2. **推荐配置**
```yaml
词典源：Cambridge Dictionary (默认)
显示音标：开启
自动发音：关闭 (避免干扰)
翻译语言：英译中
快捷键：Ctrl+Shift+D
```

3. **使用技巧**
- 选中单词后右键查询
- 悬停预览快速查看
- 收藏常用单词
- 查看历史记录

**注意事项**:
- 首次使用需下载词典数据
- 确保网络连接正常
- 定期更新词典库

### 2. Spaced Repetition ⭐⭐⭐⭐⭐

**功能定位**: 间隔重复记忆系统 (基于 SM-2 算法)

**核心功能**:
- ✅ 单词卡片制作
- ✅ 自动复习安排
- ✅ 记忆曲线追踪
- ✅ 学习统计图表
- ✅ 牌组管理

**配置步骤**:

1. **安装启用**
```
设置 → 社区插件 → Spaced Repetition → 启用
```

2. **推荐配置**
```yaml
牌组设置:
  - 新卡片每日上限：20
  - 复习卡片每日上限：100
  - 学习顺序：随机
  
算法设置:
  - 初始间隔：1 天
  - 简单倍数：1.3
  - 困难倍数：0.8
  
卡片格式:
  - 正面：问题
  - 背面：答案
  - 显示标签：开启
```

3. **卡片创建格式**

**基础格式**:
```markdown
#flashcards

**Q**: abandon 的中文意思？

**A**: v. 放弃；抛弃

#vocabulary #CET-4
```

**完形填空格式**:
```markdown
#flashcards

**Q**: The scientist made a {{c1::groundbreaking}} discovery.

**A**: groundbreaking (开创性的)

#vocabulary #cloze
```

**反向卡片格式**:
```markdown
#flashcards

**Q**: "开创性的" 用英语怎么说？

**A**: groundbreaking

#vocabulary #reverse
```

4. **复习流程**
```
1. 点击左侧边栏 Review 图标
2. 选择牌组 (如：CET-4 Words)
3. 点击 "Start Review"
4. 查看问题，思考答案
5. 点击 "Show Answer"
6. 选择掌握程度:
   - Again (忘记) - 1 分钟后
   - Hard (困难) - 2 天后
   - Good (良好) - 正常间隔
   - Easy (简单) - 延长间隔
```

**使用技巧**:
- 每日坚持复习，不要中断
- 诚实评估掌握程度
- 定期清理过时卡片
- 利用碎片时间复习

**统计数据查看**:
```
Review 面板 → Statistics
- 今日复习数
- 记忆保持率
- 学习曲线图
- 牌组分布
```

**常用查询示例**:

**1. 今日待复习单词**
````markdown
```dataview
TABLE word, difficulty, next-review
FROM "02-Vocabulary"
WHERE next-review = date(today)
SORT word ASC
```
````

**2. 本周新学单词**
````markdown
```dataview
TABLE word, level, topic, created
FROM "02-Vocabulary"
WHERE created >= date(2026-04-01)
  AND created < date(2026-04-08)
SORT created DESC
```
````

**3. 学习统计汇总**
````markdown
```dataview
TABLE 
  sum(new-words) as "新词数",
  sum(review-words) as "复习数",
  round(sum(study-time)/60, 1) as "时长 (h)"
FROM "03-Notes/Daily-Notes"
WHERE date >= date(2026-04-01)
```
````

**4. 阅读进度追踪**
````markdown
```dataview
TABLE file.name as "文章", 
       difficulty as "难度", 
       status as "状态",
       created as "日期"
FROM "01-Reading"
WHERE contains(tags, "reading")
SORT created DESC
LIMIT 10
```
````

**5. 单词掌握情况**
````markdown
```dataview
TABLE word, level, 
      round(掌握程度，1) as "掌握率"
FROM "02-Vocabulary"
WHERE contains(tags, "vocabulary")
SORT 掌握程度 DESC
```
````
