## 三、核心工作流程

### 3.1 标准学习流程

```
文章阅读 → 单词收集 → 笔记整理 → 复习巩固
    ↓           ↓           ↓           ↓
  阅读材料    单词库      学习笔记    复习计划
    ↓           ↓           ↓           ↓
 Language    HiWords +    Templater   Spaced
 Learner     Language     自动模板    Repetition
 划词查词    Learner                  间隔复习
```

### 3.2 阅读文章操作流程

1. **导入文章**
   - 在文件管理器中右键 `阅读材料/对应主题/` → 新建笔记
   - 文件命名：`YYYYMMDD_难度_文章标题`（如 `20260414_中高级_How AI Works`）
   - Templater 自动弹出模板选择，选择"阅读材料模板"

2. **阅读与查词**
   - 粘贴或输入英文文章内容到"文章正文"区域
   - 使用 **Ctrl + 鼠标悬停** 查看单词释义（Language Learner）
   - HiWords 自动高亮已保存的生词
   - 在"生词标注"表格中记录关键生词

3. **标记与批注**
   - 🟡 词汇标记：使用 `==高亮文本==` 标记重要词汇
   - 🔵 语法标记：记录重要语法结构
   - 🟢 观点标记：标记关键观点和论点
   - 在"批注与笔记"区域添加个人理解

4. **关联链接**
   - 使用 `[[文件名]]` 语法创建内部链接
   - 将生词链接到对应单词卡片
   - 将笔记链接到对应学习笔记

### 3.3 单词管理操作流程

1. **添加新单词**
   - 在 `单词库/按主题分类/对应分类/` 下新建笔记
   - 文件命名：`单词_词性_主题`（如 `elaborate_动词_学术词汇`）
   - Templater 自动弹出"单词卡片模板"

2. **填写单词信息**
   - 拼写、音标、词性（模板自动填充拼写）
   - 多义项释义（中英对照）
   - 典型例句（含中文翻译）
   - 记忆方法（词根词缀/联想记忆）
   - 同义词/反义词/词族

3. **创建复习卡片**
   - 在单词卡片底部的"复习卡片"区域添加 `#flashcards` 标签
   - 使用 `单词 :: 释义` 格式创建单行卡片
   - Spaced Repetition 插件自动识别

4. **批量导入单词**
   - 准备CSV文件，格式：`单词,词性,音标,释义,例句`
   - 使用 Templater 脚本批量创建单词卡片

### 3.4 复习操作流程

1. **日常复习**
   - 点击左侧栏的 🔁 图标或使用命令面板搜索"Spaced Repetition: Review flashcards"
   - 系统自动展示待复习的单词卡片
   - 根据记忆情况选择：较难 / 记得 / 简单
   - SM-2算法自动调整下次复习时间

2. **笔记复习**
   - 使用命令面板搜索"Spaced Repetition: Review notes"
   - 系统展示标记了 `#review` 或 `#阅读材料` 标签的笔记
   - 复习阅读材料中的知识点

3. **查看统计**
   - 打开 `统计报告/学习数据仪表盘.md` 查看综合数据
   - 打开 `统计报告/单词掌握度报告.md` 查看单词掌握分布
   - 打开 `统计报告/阅读进度报告.md` 查看阅读量统计

## 五、常见问题排查

### 5.1 插件相关问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| Language Learner查词无响应 | 本地服务未启动 | 重启Obsidian或检查8086端口是否被占用 |
| HiWords不自动高亮 | 高亮路径未匹配 | 检查设置中highlightPaths是否为"阅读材料" |
| Spaced Repetition找不到卡片 | 标签格式错误 | 确保使用 `#flashcards` 标签，卡片格式为 `A :: B` |
| Dataview查询报错 | 语法错误 | 检查DQL语法，确保字段名与frontmatter一致 |
| Templater不自动触发 | 文件夹路径不匹配 | 确认模板文件夹设置为"模板" |
| RSS Dashboard无法拉取 | 网络问题 | 检查网络连接，尝试更换RSS源 |

### 5.2 性能优化建议

- Dataview索引排除不需要的文件夹（如 `.obsidian`）
- 大型仓库可关闭Dataview的自动刷新，改为手动刷新
- HiWords高亮范围限定为"阅读材料"目录，避免全库扫描
- 定期清理RSS Dashboard的缓存数据

## 六、个性化调整建议

### 6.1 按学习目标调整

| 学习目标 | 重点插件 | 调整建议 |
|----------|----------|----------|
| 四六级备考 | Language Learner + Spaced Repetition | 侧重四六级词汇，设置每日50词复习目标 |
| 雅思托福备考 | OB English Learner + English Assistant | 增加视频听力练习，开启AI写作批改 |
| 日常阅读提升 | Language Learner + HiWords + RSS | 订阅BBC/The Economist等RSS源 |
| 学术写作 | English Assistant + Dataview | 侧重学术词汇积累，使用语法分析功能 |

### 6.2 按学习习惯调整

- **偏好视觉学习**：增加Canvas词汇本使用，利用图谱视图查看知识关联
- **偏好听觉学习**：开启Language Learner自动发音，使用OB English Learner的TTS功能
- **偏好系统学习**：严格按复习计划执行，使用Spaced Repetition的每日复习
- **偏好碎片学习**：利用RSS Dashboard随时阅读短文，HiWords自动积累生词
