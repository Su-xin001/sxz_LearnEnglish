# 常用英语词根词缀速查

## 一、常用前缀

| 前缀 | 含义 | 示例 |
|------|------|------|
| un- | 不，否定 | unhappy, unable |
| in-/im-/il-/ir- | 不，否定 | invisible, impossible, illegal, irregular |
| dis- | 不，相反 | disagree, discover |
| mis- | 错误 | misunderstand, mistake |
| re- | 再次，回 | rewrite, return |
| pre- | 前，预先 | predict, prevent |
| post- | 后 | postpone, postwar |
| over- | 过度，在上 | overcome, overlook |
| under- | 不足，在下 | underestimate, underground |
| out- | 超过，外 | outperform, outdoor |
| sub- | 下，次 | submarine, subtitle |
| super- | 超，上 | supermarket, supernatural |
| inter- | 之间，相互 | international, interact |
| trans- | 跨越，转变 | transport, translate |
| ex- | 前任，向外 | ex-president, export |
| anti- | 反对 | antibody, antisocial |
| auto- | 自我，自动 | automatic, autobiography |
| bi- | 二 | bilingual, bicycle |
| multi- | 多 | multicultural, multiply |
| semi- | 半 | semiconductor, semi-final |

## 二、常用后缀

### 名词后缀

| 后缀 | 含义 | 示例 |
|------|------|------|
| -tion/-sion | 动作，状态 | education, decision |
| -ment | 行为，结果 | development, achievement |
| -ness | 性质，状态 | happiness, kindness |
| -ity/-ty | 性质，状态 | ability, reality |
| -er/-or | 做事的人 | teacher, actor |
| -ist | 专业人员 | scientist, artist |
| -ism | 主义，学说 | capitalism, realism |
| -ure | 行为，结果 | failure, pressure |

### 形容词后缀

| 后缀 | 含义 | 示例 |
|------|------|------|
| -ful | 充满 | beautiful, helpful |
| -less | 无，没有 | hopeless, careless |
| -ous/-ious | 充满的 | dangerous, serious |
| -ive | 倾向的 | active, creative |
| -able/-ible | 可...的 | readable, possible |
| -al | 属于的 | national, natural |
| -ic | 与...有关的 | scientific, historic |

### 动词后缀

| 后缀 | 含义 | 示例 |
|------|------|------|
| -ize/-ise | 使成为 | realize, organize |
| -fy | 使成为 | simplify, classify |
| -en | 使成为 | widen, strengthen |
| -ate | 做，使 | elaborate, activate |

### 副词后缀

| 后缀 | 含义 | 示例 |
|------|------|------|
| -ly | 以...方式 | quickly, carefully |
| -ward(s) | 方向 | forward, towards |
