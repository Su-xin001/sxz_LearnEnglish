# Obsidian英语学习插件评估报告

## 一、评估概览

本报告对Obsidian社区生态中与英语学习高度相关的插件进行系统性评估，从功能特性、资源占用、用户评价及适用场景四个维度进行分析，为最终插件组合决策提供依据。

---

## 二、备选插件详细评估

### 1. Language Learner（obsidian-language-learner）

| 评估维度 | 详细说明 |
|----------|----------|
| **版本** | 0.2.7 |
| **功能特性** | 阅读查词一体化：支持鼠标悬停查词、划词翻译；集成有道/剑桥/句酷/沪江/DeepL多词典；内置单词数据库管理；支持生词本自动收集；提供阅读模式优化排版；支持机器翻译对照阅读 |
| **资源占用** | 中等。本地运行词典查询服务（端口8086），需占用约30-50MB内存；词典数据按需加载，不影响整体性能 |
| **用户评价** | ⭐⭐⭐⭐ 中文用户群体评价较高，尤其适合中英互译学习场景；部分用户反馈词典API偶尔不稳定 |
| **适用场景** | 日常英文文章阅读辅助、划词翻译、生词收集与复习、多词典对照查询 |
| **优势** | 多词典集成、中文用户友好、阅读查词流程顺畅 |
| **不足** | 界面仅中文、词典API依赖网络、本地服务需额外端口 |

**结论：✅ 核心推荐 — 作为阅读查词和词典集成的核心插件**

---

### 2. HiWords（hi-words）

| 评估维度 | 详细说明 |
|----------|----------|
| **版本** | 0.5.4 |
| **功能特性** | 自动高亮生词：阅读时自动标记已保存的单词；悬停显示释义；支持单词掌握度标记；Canvas词汇本集成；TTS发音（有道语音）；AI词典扩展查询；自动布局词汇卡片 |
| **资源占用** | 低。轻量级插件，内存占用<20MB；Canvas文件解析高效 |
| **用户评价** | ⭐⭐⭐⭐⭐ 新兴插件，设计理念先进；自动高亮功能广受好评；与Canvas集成方式创新 |
| **适用场景** | 阅读时生词自动标记、词汇量可视化追踪、渐进式词汇积累 |
| **优势** | 自动高亮体验优秀、掌握度标记直观、Canvas集成灵活 |
| **不足** | 功能相对专注、依赖Canvas格式、AI查询需额外配置API |

**结论：✅ 核心推荐 — 作为阅读生词高亮和词汇量追踪的核心插件**

---

### 3. Spaced Repetition（obsidian-spaced-repetition）

| 评估维度 | 详细说明 |
|----------|----------|
| **版本** | 1.13.6 |
| **功能特性** | 基于SM-2算法的间隔重复复习；支持单行/多行卡片格式；支持填空题（Cloze）模式；笔记复习功能；自定义标签筛选卡片组；复习数据存储在笔记中；支持正反卡片；可自定义复习间隔和难度调整 |
| **资源占用** | 低。纯本地计算，无网络依赖；内存占用<15MB；复习数据嵌入笔记frontmatter |
| **用户评价** | ⭐⭐⭐⭐⭐ Obsidian生态中最成熟的复习插件；社区活跃度高；算法实现可靠 |
| **适用场景** | 单词卡片复习、知识点间隔重复、填空题练习、笔记内容复习 |
| **优势** | SM-2算法成熟可靠、数据存储透明（在笔记中）、高度可定制、支持多种卡片类型 |
| **不足** | 无内置统计图表（需配合Dataview）、UI较为朴素 |

**结论：✅ 核心推荐 — 作为间隔重复记忆和单词复习的核心插件**

### 4. OB English Learner（ob-english-learner-1.5）

| 评估维度 | 详细说明 |
|----------|----------|
| **版本** | 1.5 |
| **功能特性** | YouTube视频学习系统：自动获取视频字幕；SRT字幕生成；Bases数据库集成；AI翻译与格式化；语音转文字；TTS朗读；双语字幕生成；自定义笔记模板；视频内容问答 |
| **资源占用** | 中高。AI功能依赖外部API（需配置API Key）；视频处理需网络带宽；本地缓存占用磁盘空间 |
| **用户评价** | ⭐⭐⭐⭐ 视频学习场景独特；AI集成深度；配置相对复杂 |
| **适用场景** | YouTube英文视频学习、听力训练、视频字幕学习、AI辅助翻译 |
| **优势** | 视频学习场景全覆盖、AI深度集成、字幕处理能力强 |
| **不足** | 依赖AI API（有成本）、配置复杂、主要面向YouTube场景 |

**结论：✅ 推荐安装 — 作为视频/听力学习场景的补充插件**

### 5. English Assistant（obsidian-english-assistant）

| 评估维度 | 详细说明 |

| **功能特性** | AI英语语法分析：语法错误检测与修正建议；写作风格改进建议；多版本改写（正式/随意/简洁）；词汇提取与学习；本地词典支持；TTS发音；进度追踪与打卡；AI聊天练习 |

| **不足** | AI功能需API Key、语法分析依赖模型质量 |

**结论：✅ 推荐安装 — 作为写作辅助和语法分析的补充插件**

### 6. Dataview（dataview）

| 评估维度 | 详细说明 |
|----------|----------|
| **版本** | 0.5.68 |
| **功能特性** | 数据查询引擎：DQL查询语言；JavaScript API；支持TABLE/LIST/TASK/CALENDAR四种视图；frontmatter元数据查询；内联查询；支持数据聚合与计算；可生成动态统计报告 |

| **用户评价** | ⭐⭐⭐⭐⭐ Obsidian生态基石级插件；功能强大且灵活；学习曲线较陡 |
| **适用场景** | 学习数据统计、单词库查询、阅读材料管理、动态仪表盘、进度追踪 |
| **优势** | 查询能力极强、生态兼容性好、可实现复杂统计 |
| **不足** | DQL语法需学习、大型仓库索引较慢 |

**结论：✅ 核心推荐 — 作为数据统计和动态查询的核心基础设施**

## 四、插件冲突与兼容性分析

| 潜在冲突 | 影响程度 | 解决方案 |
|----------|----------|----------|
| Language Learner与HiWords查词功能重叠 | 低 | Language Learner负责划词翻译，HiWords负责自动高亮，功能互补 |
| Spaced Repetition与Language Learner复习功能重叠 | 中 | 以Spaced Repetition为主力复习引擎，Language Learner复习功能作为辅助 |
| OB English Learner与English Assistant均需AI API | 低 | 可共用同一API Key，注意调用频率限制 |
| Dataview索引与大型仓库性能 | 中 | 配置排除不需要索引的文件夹 |

---

## 五、安装与配置优先级

1. **第一优先级**（立即配置）：Dataview → Templater → Language Learner → HiWords → Spaced Repetition
2. **第二优先级**（按需配置）：OB English Learner → English Assistant → RSS Dashboard
3. **第三优先级**（辅助增强）：Calendar → Various Complements → Media Extended → Obsidian Git
