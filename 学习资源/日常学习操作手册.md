# 📖 日常学习操作手册

---

## 一、标准学习流程

### 每日学习四步法

```
Step 1: 文章阅读（20-30分钟）
   ↓
Step 2: 单词收集（10-15分钟）
   ↓
Step 3: 笔记整理（10-15分钟）
   ↓
Step 4: 复习巩固（15-20分钟）
```

---

## 二、Step 1 — 文章阅读

### 操作步骤

1. **选择阅读材料**
   - 打开 `阅读材料/` 目录，选择对应主题子目录
   - 或通过 RSS Dashboard 获取最新英文资讯
   - 或导入外部文章（见下方导入方法）

2. **创建阅读笔记**
   - 在对应主题目录下右键 → 新建笔记
   - 按命名规则输入文件名：`YYYYMMDD_难度_标题`
   - Templater 自动弹出模板，按提示填写元数据

3. **开始阅读**
   - 将文章内容粘贴到"📖 文章正文"区域
   - 遇到生词：**Ctrl + 鼠标悬停** → Language Learner 弹出释义
   - HiWords 自动高亮已保存的生词（下划线标记）
   - 需要翻译整段：选中段落后使用翻译功能

4. **标记重点**
   - 词汇标记：选中文字 → 使用 `==高亮==` 语法
   - 在"批注与笔记"区域记录理解和问题

### 文章导入方法

| 来源 | 操作方法 |
|------|----------|
| 网页文章 | 复制粘贴到阅读材料正文区域 |
| PDF文件 | 使用Obsidian内置PDF查看器，手动摘录关键段落 |
| EPUB文件 | 使用Calibre转换为Markdown后导入 |
| RSS订阅 | RSS Dashboard自动拉取，保存到仓库 |
| YouTube视频 | OB English Learner自动获取字幕 |

---

## 三、Step 2 — 单词收集

### 操作步骤

1. **从阅读中收集**
   - 阅读时遇到生词，使用 Language Learner 查询
   - 选中单词 → 右键 → HiWords: Add to vocabulary（添加到生词本）
   - HiWords 自动在生词本中创建条目

2. **创建完整单词卡片**
   - 在 `单词库/按主题分类/对应分类/` 下新建笔记
   - 文件命名：`单词_词性_主题`
   - Templater 自动弹出"单词卡片模板"
   - 按模板字段填写完整信息

3. **添加复习卡片**
   - 在单词卡片的"复习卡片"区域确保有 `#flashcards` 标签
   - 格式：`单词 :: 释义`
   - 可添加多个卡片：词义卡片、例句填空卡片

### 批量导入单词

1. 准备CSV文件，格式如下：
   ```
   单词,词性,音标,中文释义,英文释义,例句,主题
   elaborate,动词,/ɪˈlæbəreɪt/,详细阐述,to explain in detail,Could you elaborate on that?,学术
   ```

2. 将CSV文件放入仓库根目录

3. 使用Dataview查询读取CSV数据：
   ```dataview
   TABLE FROM csv("文件名.csv")
   ```

4. 根据查询结果逐个创建单词卡片

## 四、Step 3 — 笔记整理

### 操作步骤

1. **创建学习笔记**
   - 在 `学习笔记/按日期/` 下新建笔记
   - 文件命名：`YYYYMMDD_学习主题`
   - Templater 自动弹出"学习笔记模板"

2. **填写笔记内容**
   - 记录核心知识点
   - 整理重点单词表
   - 总结语法要点
   - 记录核心收获和待解决问题

3. **建立关联链接**
   - 使用 `[[文件名]]` 链接到阅读材料
   - 使用 `[[单词_词性_主题]]` 链接到单词卡片
   - 使用 `[[复习计划文件名]]` 链接到复习计划

4. **设置复习提醒**
   - 勾选笔记底部的复习计划复选框
   - 或为笔记添加 `#review` 标签

---

## 五、Step 4 — 复习巩固

### 操作步骤

1. **闪卡复习**
   - 点击左侧栏 🔁 图标
   - 或使用快捷键 `Ctrl+Shift+S`
   - 系统展示今日待复习的单词卡片
   - 回忆答案后翻转卡片
   - 根据记忆情况选择：较难 / 记得 / 简单

2. **笔记复习**
   - 使用命令面板 → "Spaced Repetition: Review notes"
   - 复习标记了 `#review` 的阅读材料
   - 重新阅读并评估掌握程度

3. **查看学习统计**
   - 打开 `统计报告/学习数据仪表盘.md`
   - 查看今日学习数据
   - 关注掌握率变化趋势

## 六、每周学习流程

### 周一：制定计划

1. 创建本周复习计划
   - 在 `复习计划/短期计划/` 下新建笔记
   - 文件命名：`YYYYMM_周计划_主题`
   - 设定本周学习目标和每日安排

### 周二至周六：日常学习

- 按每日四步法执行
- 完成复习计划中的每日任务
- 勾选复习计划中的完成项

### 周日：总结回顾

1. 查看学习数据仪表盘
2. 统计本周新增单词数和掌握率
3. 更新复习计划的进度追踪表
4. 调整下周学习计划

## 七、常见操作详解

### 7.1 使用Language Learner查词

1. 确保Language Learner插件已启用
2. 在阅读英文文章时，按住 **Ctrl** 键 + 鼠标悬停在单词上
3. 弹出词典窗口，显示：
   - 有道词典释义（优先级1）
   - 剑桥词典释义（优先级2）
   - 句酷例句（优先级3）
   - 沪江词典（优先级4）
   - DeepL翻译（优先级5）
4. 点击发音按钮收听单词读音

### 7.2 使用HiWords管理生词

1. **添加生词**：选中单词 → 右键 → "HiWords: Add to vocabulary"
2. **查看释义**：鼠标悬停在已保存的单词上
3. **标记掌握**：右键 → "HiWords: Mark as mastered"
4. **查看词汇本**：打开 `单词库/按掌握程度/` 下的词汇本文件

### 7.3 使用Spaced Repetition复习

1. **创建闪卡**：在任意笔记中添加以下格式
   ```
   #flashcards
   
   单词 :: 释义
   问题 :: 答案
   ```

2. **创建填空题**：使用高亮语法
   ```
   #flashcards
   
   The ==paradigm== shift demands rethinking.
   ```

3. **开始复习**：
   - 点击左侧栏闪卡图标
   - 选择卡片组
   - 逐张复习

4. **复习策略**：
   - 较难：间隔大幅缩短（1-2天后复习）
   - 记得：间隔正常增长
   - 简单：间隔加速增长

### 7.4 使用RSS Dashboard获取阅读材料

1. 打开RSS Dashboard视图
2. 点击"+"添加订阅源
3. 推荐英文资讯源：
   - BBC News: `https://feeds.bbci.co.uk/news/rss.xml`
   - The Economist: `https://www.economist.com/rss`
   - MIT Technology Review: `https://www.technologyreview.com/feed/`
4. 阅读感兴趣的文章
5. 点击"Save to vault"保存到阅读材料目录

## 八、典型问题排查

| 错误现象 | 可能原因 | 解决步骤 |
|----------|----------|----------|
| 查词弹窗不出现 | Language Learner服务未启动 | 1. 检查8086端口 2. 重启Obsidian 3. 检查插件是否启用 |
| 生词不被高亮 | HiWords词汇本路径错误 | 1. 检查HiWords设置 2. 确认词汇本文件存在 3. 刷新词汇本 |
| 闪卡数量为0 | 标签或格式错误 | 1. 确认 `#flashcards` 标签 2. 检查 `::` 分隔符 3. 重启插件 |
| Dataview表格为空 | frontmatter字段不匹配 | 1. 检查字段名大小写 2. 确认 `类型` 字段值正确 3. 等待索引刷新 |
| 模板不自动应用 | Templater配置问题 | 1. 确认模板文件夹为"模板" 2. 检查trigger_on_file_creation 3. 手动插入模板测试 |
| 复习间隔异常 | SM-2算法参数问题 | 1. 检查baseEase设置 2. 重置卡片调度数据 3. 调整lapsesIntervalChange |
