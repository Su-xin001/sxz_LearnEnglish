# 写作练习导航

> [!tip-en] 写作练习流程
> 1. **选择题目** — 从考试题目或日常话题中选择
> 2. **构思大纲** — 列出文章结构和要点
> 3. **限时写作** — 在规定时间内完成初稿
> 4. **自我检查** — 用检查清单逐项核对
> 5. **获取反馈** — 使用 English Assistant 插件获取AI批改
> 6. **修改提升** — 根据反馈修改，积累好词好句

## 常用写作模板

### 开头段
- **现象引入**：Nowadays, there is a growing concern over...
- **观点引入**：When it comes to..., opinions vary from person to person.
- **数据引入**：As is shown in the chart, ...

### 主体段
- **列举论点**：First and foremost... Moreover... Last but not least...
- **对比论证**：On the one hand... On the other hand...
- **举例论证**：A case in point is... / Take... for example

### 结尾段
- **总结观点**：In conclusion / To sum up / All in all
- **建议措施**：It is high time that we took measures to...
- **展望未来**：Only in this way can we...
