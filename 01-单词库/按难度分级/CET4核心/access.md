## 释义

<div class="definition-block">

**常用义项**

1. **n.** 通道；访问权
   - <div class="example-sentence">Students have free ==access== to the library.
   <span class="chinese-translation">学生可以自由使用图书馆。</span></div>
   - <div class="example-sentence">The building provides wheelchair ==access==.
   <span class="chinese-translation">该建筑提供轮椅通道。</span></div>
2. **v.** 访问；存取
   - <div class="example-sentence">You can ==access== the file from any device.
   <span class="chinese-translation">你可以从任何设备访问这个文件。</span></div>
