# 单词总表

> [!tip-en] 使用说明
> - 每个单词创建独立笔记文件，存放在 `01-单词库/` 对应子文件夹中
> - 使用 `Alt+1` 快速插入单词卡模板
> - 使用 `Alt+R` 开始间隔重复复习
> - Hi-Words 插件会在阅读时自动高亮已学单词

## 学习统计

```dataview
TABLE 
  length(rows) as 数量
FROM "01-单词库"
FLATTEN file.tags as tag
GROUP BY tag
SORT 数量 DESC
```

## 按难度分类


## 按主题分类

```dataview
TABLE 主题, 释义, 难度
FROM "01-单词库"
WHERE length(主题) > 0
```
