# 🧬 词根词缀索引

## 常用前缀

| 前缀 | 含义 | 示例单词 |
|------|------|----------|
| un- | 不，非 | unable, uncommon |
| re- | 再次，回 | review, rebuild |
| pre- | 前，先 | predict, prevent |
| dis- | 不，相反 | discover, disagree |
| over- | 过度，在上 | overcome, overlook |
| mis- | 错误 | misunderstand, mistake |
| inter- | 之间，相互 | interact, international |
| trans- | 跨越，转变 | transform, transport |

## 常用后缀

| 后缀 | 含义 | 示例单词 |
|------|------|----------|
| -tion/-sion | 名词化 | education, decision |
| -ment | 名词化 | development, achievement |
| -ness | 名词化 | happiness, weakness |
| -ful | 充满的 | beautiful, helpful |
| -less | 无，没有 | careless, endless |
| -able/-ible | 可...的 | available, possible |
| -ly | 副词化 | quickly, carefully |
| -ize/-ise | 动词化 | realize, organize |
