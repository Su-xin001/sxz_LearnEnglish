# 📚 单词库

> [!tip] 快速操作
> - **添加单词**：使用 `Ctrl+P` → 输入 "单词卡片模板" 快速创建
> - **划词添加**：在阅读材料中选中单词 → 右键添加到单词库
> - **批量导入**：将 CSV 文件放入 `08-资源/导入` 文件夹

## 📊 单词统计

```dataview
TABLE 
  length(rows) as 数量
FROM "01-单词库"
WHERE word
GROUP BY difficulty
SORT difficulty ASC
```

## 📋 全部单词

```dataview
TABLE 
  phonetic_us AS "美式音标",
  pos AS "词性",
  difficulty AS "难度",
  memory_stage AS "记忆阶段",
  date_added AS "添加日期",
  mastery AS "掌握度"
FROM "01-单词库"
WHERE word
SORT date_added DESC
```

## 🏷️ 按词性分类

```dataview
TABLE 
  phonetic_us AS "音标",
  difficulty AS "难度",
  mastery AS "掌握度"
FROM "01-单词库"
WHERE word AND contains(pos, "noun")
SORT word ASC
```

## 📈 按记忆阶段

```dataview
TABLE 
  word AS "单词",
  difficulty AS "难度",
  date_added AS "添加日期"
FROM "01-单词库"
WHERE word AND memory_stage = "新词"
SORT date_added DESC
```
