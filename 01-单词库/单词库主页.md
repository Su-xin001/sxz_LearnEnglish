# 📚 单词库

> [!tip] 快捷操作
> - **Ctrl+Shift+W** — 快速添加单词
> - **Ctrl+Shift+A** — 从选中文本添加单词
> - **Ctrl+Shift+C** — 管理当前单词分类
> - **Ctrl+Shift+T** — 快捷添加分类标签
> - **Ctrl+P** → "批量导入CSV" — 批量导入单词
> - **Ctrl+P** → "浏览分类视图" — 分类浏览
> - **Ctrl+P** → "批量分类管理" — 批量修改分类
> - 右键编辑器 → 选中英文单词 → 添加到单词库
> - 右键文件 → 管理单词分类 / 快捷添加分类

## 📊 单词统计

```dataview
TABLE 
  length(rows) as 数量
FROM "01-单词库"
WHERE word
GROUP BY difficulty
SORT difficulty ASC
```

## 📥 批量导入

> [!example] CSV导入说明
> 1. 准备CSV文件，必须包含 `word` 和 `meaning` 列
> 2. 可选列：`phonetic_uk`, `phonetic_us`, `pos`, `difficulty`, `topic`, `example_en`, `example_zh`, `memory`, `synonyms`, `antonyms`, `derivatives`
> 3. 多值字段用分号分隔，如 `pos: verb;adjective`
> 4. 将CSV文件放入 `08-资源/导入` 文件夹
> 5. 使用 **Ctrl+P** → "批量导入CSV单词" 命令
> 
> **示例CSV格式：**
> ```
> word,phonetic_us,pos,meaning,difficulty,topic,example_en,example_zh
> abandon,/əˈbændən/,verb,放弃；抛弃,CET4,社会,He abandoned his plan.,他放弃了计划。
> ```
