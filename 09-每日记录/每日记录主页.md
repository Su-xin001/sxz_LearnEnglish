# 📅 每日记录

> *记录每一天的学习历程*

---

## ⚡ 快速操作

| 操作 | 快捷方式 | 说明 |
|------|----------|------|
| 📝 打开今日日记 | `Alt+T` | 打开/创建今天的日记 |
| 📋 新建学习日志 | `Ctrl+P` → "学习日志" | 创建独立的学习日志 |
| 📅 日历导航 | 日历插件 | 点击日期查看对应日记 |

---

## 📖 最近日记

```dataview
TABLE date AS "日期", choice(length(filter(file.tags, (t) => t = "每日学习")), "✅", "❌") AS "学习记录"
FROM "09-每日记录/日记"
SORT file.name DESC
LIMIT 14
```

## 📋 最近学习日志

```dataview
LIST
FROM "09-每日记录/学习日志"
SORT file.name DESC
LIMIT 10
```

---

## 📊 本月学习统计

```dataview
TABLE length(rows) AS "日记天数"
FROM "09-每日记录/日记"
WHERE date >= date(today) - dur(30 days)
FLATTEN 1 as count
GROUP BY true
```
