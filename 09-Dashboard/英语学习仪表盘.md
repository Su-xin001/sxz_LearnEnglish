---

### � 词汇学习

#### 掌握度分布

```dataview
TABLE WITHOUT ID
  choice(mastery = 0, "⬜ 未学习",
  choice(mastery = 1, "🟦 初识",
  choice(mastery = 2, "🟩 认识",
  choice(mastery = 3, "🟨 熟悉",
  choice(mastery = 4, "🟧 掌握",
  choice(mastery = 5, "🟥 精通", "❓"))))) AS 等级,
  length(rows) AS 数量
FROM "02-Vocabulary/Words"
GROUP BY mastery
SORT mastery ASC
```

#### 最近学习的单词

```dataview
TABLE WITHOUT ID
  file.link AS 单词,
  meaning-zh AS 释义,
  difficulty AS 难度,
  mastery AS 掌握度
FROM "02-Vocabulary/Words"
SORT date DESC
LIMIT 10
```

#### 待重点复习

```dataview
TABLE WITHOUT ID
  file.link AS 单词,
  meaning-zh AS 释义,
  mastery AS 掌握度
FROM "02-Vocabulary/Words"
WHERE mastery <= 1
SORT mastery ASC
LIMIT 10
```
