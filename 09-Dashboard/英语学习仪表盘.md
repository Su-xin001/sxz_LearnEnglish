## 📊 英语学习仪表盘

### 📖 最近阅读
```dataview
TABLE source AS 来源, difficulty AS 难度, read-date AS 阅读日期
FROM "01-Reading"
SORT read-date DESC
LIMIT 10
```

### 📝 最近学习的单词
```dataview
TABLE meaning-zh AS 释义, pos AS 词性, mastery AS 掌握度
FROM "02-Vocabulary/Word-Lists"
SORT date DESC
LIMIT 20
```
